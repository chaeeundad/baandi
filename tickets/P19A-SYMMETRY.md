TASK_ID: P19A-SYMMETRY
GOAL: Master plan MF11 (and performance backlog B15 / exceed-qe-plan stage S4b): crystal symmetry. Detect the space-group operations of the input structure, reduce the k-point mesh to its irreducible set with correct weights, and symmetrize the density, so that k-point-rich calculations do the same physics with far fewer k points (QE's default does this; BAANDI compared with QE only with symmetry off on both sides, so QE's best configuration is about 3 times cheaper on shifted 4x4x4 fcc silicon: about 10 irreducible points instead of 32, an unrecorded standard result: measure it here). Contracts: docs/architecture/state-contracts.md (SymmetryOperation: integer rotation [3,3], fractional translation [3], atom permutation, spin action identity or swap, antiunitary flag; KOrbitMap: every full k id, representative id, operation id, reciprocal integer shift, phase convention exp(-i(k+G).tau), multiplicity; weights sum to one), docs/validation/stage-oracles.md row MF11, ADR 0031, ADR 0033.
SCOPE: (1) dft-geometry: symmetry detection from the lattice and atoms: find all lattice point-group operations (rotations preserving the metric to a stated tolerance, search over integer matrices), with fractional translations that map the atom set (species aware, tolerance stated, in Bohr and fractional units) onto itself; produce the operation list with atom permutations; deterministic ordering; no external library unless a license, maintenance and Apple Silicon review is recorded in docs/dependencies.md and the orchestrator approves (ask first; the default is to implement it in-house with an independent test oracle, because spglib-class code is large); time reversal handled as k to -k as today. (2) k-point reduction: reduce a Monkhorst-Pack mesh (shifted or not, skewed cell) with the group plus time reversal to irreducible points with exact multiplicities (weights sum to 1 within 1e-14), the full mesh as the oracle; reject meshes that are not invariant under the group in the requested configuration (never reduce an invalid shifted mesh silently: the shifted mesh may only be reduced by operations that map the shifted mesh to itself; detect and use the subgroup that keeps it invariant). (3) density symmetrization: after each density build from irreducible k points, symmetrize in G space with the explicit phase factors of fractional translations (the contract's phase convention); apply the same rule to the unpolarized density and to collinear spin channels (operations with spin action identity only; spin-swapping operations and antiunitary time reversal for magnetic states stay disabled with a clear reason, as the contract says). The XC and density-dependent pieces stay unchanged. (4) Interaction with the engine: eigenvalues and weights per irreducible k reported with their multiplicities; results.json additive block (`symmetry`: operations count, point group label if easily derived, irreducible k count, tolerance); CLI `[symmetry] mode = "off" | "auto"` default OFF (so legacy behaviour is bit-identical) and `tolerance_bohr`; with auto: invariance checks for external fields, constraints and Hubbard terms (not present yet: reject if any such term is active); preflight messages in ADR 0022 style; band structure and density output unchanged in format (density is the full-grid symmetrized density). (5) Oracles (stage-oracles MF11): full-mesh versus reduced SCF on diamond Si 2 atoms (4x4x4 shifted and unshifted), a skewed low-symmetry cell, the 8-atom cubic cell, MgO rocksalt (PseudoDojo via DFT_NC_DIR, ignored test), a slab-like cell, and a spin-polarized synthetic case: total energy difference <= 1e-10 Ha and density distance <= 1e-9 Bohr^-3/2 under tightened SCF, moment difference <= 1e-9 mu_B, weights sum error <= 1e-14; group property tests (closure, inverse, composition), k multiplicity tests, an independent Python or test-side brute-force reconstruction of the full mesh from the irreducible set with the explicit phases; negative tests: an operation set that does not leave a shifted mesh invariant, a structure with a tolerance-edge atom position, noninvariant constraints must reject. (6) Measurement of the benefit: number of irreducible k points and wall time on k444s (diamond Si 4x4x4 shifted) full versus reduced, Mac observation plus counters (work is the evidence).
RULES: default `off` leaves every existing result bit-identical (bench_scf --require-identical); no relaxation of tolerances; determinism across thread counts; hot-path rules; no unsafe; no QE source (QE's behaviour is only known from outputs in tests/reference); if the stored QE outputs list the number of symmetry operations and irreducible k points for a case, compare your counts with them and report; the spin path of P13B and the occupations path of P17B must keep working with symmetry off and, for Fermi-Dirac and unpolarized, with symmetry on (test).
