# What we know about QE 7.6 (from our runs, dev08, Open MPI 5.0.8)

- Start: default `startingwfc = atomic+random`, `startingpot = atomic` (free-atom superposition, charge 31.9960 renormalised to 32). `startingwfc = atomic` is faster on large cells (si32 1e-10: 186 to 35 h_psi calls, 6.7 to 3.5 s) and freezes the SCF count across core counts (8 SCF at 1, 4, 8 ranks); `random` is worse everywhere. The comparison target is QE's best configuration, so use `atomic`.
- SCF count: 12 / 10 / 10 (1e-8) and 15 / 13 / 13 (1e-10) for si8 / si16 / si32 with the default start; invariant under 1e-7 and 1e-3 Bohr displacements; mixing beta 0.5, ndim 6 instead of 0.7, 8 changes si32 by -6 percent only.
- Eigensolver tolerance: `ethr` starts at 1e-2 (first iteration, 7.6e-4 on si32) and then follows 0.1 x estimated density error, spanning eleven orders of magnitude; it tests the eigenvalue change (about the residual squared over a gap); BAANDI's strict profile tests the residual norm, so equal numbers are not equal strictness. BAANDI's iteration-1 tolerance (1e-2) is not tighter than QE's.
- Timers (1 core, si32 1e-8): vloc_psi 2.48 s of 4.94, calbec + add_vuspsi 0.45, regterg overhead and update 0.50, rdiaghg 0.32, sum_band 0.47, v_of_rho 0.09, mix_rho 0.07; the launcher adds 0.15 s at si8; fftw is inside vloc_psi and sum_band.
- Hard cells (fixed occupations, no smearing, nosym): si-skew 51 / 180 SCF, si-low 11 / 15, si-elongated 137 / 200 (1e-10 not converged), si-slab 200 / 200 (neither converged); QE's low SCF count is a property of well-conditioned bulk.
- Energy offset to BAANDI for Si.pz-vbc.UPF LDA-PZ: 1.273e-6 Ha per atom at fixed density, proportional to 1/volume, a fixed relative error 1.7473e-5 of the G=0 local term: QE's plain mesh integral omits the first interval [0, r_1] of the logarithmic mesh (r_1 = 0.001308), BAANDI includes it analytically; `pseudo.local_mesh = qe_like_g0` reproduces QE (si8 strict 1.7e-9 Ha difference). PseudoDojo meshes start at r = 0, where this does not arise.
- QE's multi-core runs here are MPI with default binding (one rank per physical core, package 0); BAANDI's are threads on the same cores; QE's `K_POINTS gamma` real path is its best Gamma configuration.
