TASK_ID: ONEPATH-3B-SPIN-COST
GOAL: Find and fix why a zero-moment collinear run (Si8 Gamma, PBE, PseudoDojo NC, standard path, plain input) needed 22 SCF steps and 2 verification attempts on dev08 (binary 006baaf) where the unpolarized run needed 9 and 1 (|dE| 6.4e-11 Ha, density SHA different; the ONEPATH-3 U1 check allowed SCF counts within 1). Make the zero-moment spin run follow the unpolarized trajectory within the rounding class without changing the unpolarized path and without relaxing any tolerance.
OWNED_FILES: crates/dft-engine/src/collinear.rs (atomic start of a cold fixed-sector solve, result field), crates/dft-engine/src/scf.rs (spin channels prepare the atomic species; `clear_atomic_start`), crates/dft-engine/src/finite_temperature.rs (scalar FD clears it), crates/dft-engine/tests/spin_atomic_start.rs (new), crates/dft-engine/tests/common/mod.rs (orbital fixture), crates/dft-engine/AGENTS.md, crates/dft-cli/src/spin_run.rs (atomic_start record), crates/dft-cli/src/preflight.rs (fallback prediction), crates/dft-cli/tests/atomic_start.rs, docs/decisions/0042-atomic-start-default.md (amendment), docs/user/collinear-spin.md, docs/performance/requests/onepath3b-spin-cost.md (new), docs/performance/attempts-ledger.md (row ONEPATH-3B), artifacts/task_titles.json, this ticket.
ACCEPTANCE (fixed before measuring): (a) Si8 PBE zero-moment spin vs unpolarized, both complex standard path: SCF counts equal or within 1, same verification attempt count, |dE| <= 1e-10 Ha; unpolarized path numbers unchanged (bit-identical: no change on its code path). (b) Regression test on a synthetic fixture with atomic orbitals: the ONEPATH-3 (a) bounds |dE| <= 1e-10 Ha, density distance <= 1e-9, SCF counts within 1, per-iteration estimates within 1e-6 relative, equal attempt counts. (c) Fermi-Dirac (scalar and collinear) unchanged: free-electron start with reason "Fermi-Dirac occupations". (d) No tolerance relaxed; scripts/check.sh four gates PASS.

ROOT CAUSE: the spin driver never used the atomic start. `ScfProblem::construct` recorded the fallback reason "spin-polarized occupations" for every spin channel (ADR 0042 listed collinear spin as an exclusion), and `CollinearProblem::map` started cold solves from the free-electron plane waves. The PseudoDojo Si file has PP_PSWFC, so the unpolarized run started from the atomic subspace and the spin run did not. The Mac synthetic fixtures of ONEPATH-3 have no PP_PSWFC, so both runs fell back to free electrons there and agreed to 1e-15 Ha. Mixing (Pulay per channel is exactly half of the closed-shell step for equal channels: scale-invariant least squares and relative spectral cut), the estimator (d_m = 0), the ratchet, the first-iteration redo, the band count, the preconditioner and the spin XC at zeta = 0 were checked and are not the cause: with the free-electron start on both sides the SCF counts are equal (Si8 18 vs 18; the per-step values differ from step 1 at the 1e-3 Ha level; not traced further, the likely amplifier is that the free-electron start of the cubic cell cuts degenerate plane-wave shells at the band count, so rounding-level potential differences pick different start vectors at the 5e-3 Ha first tolerance) and the synthetic dimer agrees to dE 3e-16 Ha.

FIX: cold fixed-sector solves of the collinear driver build the atomic span once per k (shared by both channels, same basis) and run Rayleigh-Ritz in each channel's own Hamiltonian, exactly the closed-shell construction (`atomic_start::span` / `ritz`). Fermi-Dirac problems (collinear and scalar) drop the prepared species with the reason "Fermi-Dirac occupations", as the closed-shell FD rule. `CollinearResult.atomic_start` and results.json `atomic_start` record it; preflight no longer predicts a spin fallback. `scf.start_wavefunctions = "free_electron"` keeps the old start.
