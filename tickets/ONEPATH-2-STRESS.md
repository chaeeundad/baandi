INPUT_CONTRACT:
- `run` with `output.stress = true`: standard path, verification on; `single_path.status = "applied"`. The engine accepts the state exactly when forces accept it (passed verification; unchanged force precondition). `stress.preconditions` = {convergence_profile "standard", converged, fixed_point_verification_passed, standard_threshold_ha, verification_attempts, verification_coulomb_error_ha, verification_residual_bound_ha, state}. `verify = "off"` with stress is an input error.
- Cutoff scans (isotropic Pulay estimate, three SCFs at Ecut, 1.05 Ecut, 1.10 Ecut): for a standard caller every scan runs the standard path WITH the fixed-point verification at the scan threshold `min(1e-9 Ha, scf.standard_threshold_ha)` (never looser than before; follows a tighter caller). A scan that fails there is repeated once at the caller's threshold when that is looser; no strict fallback. The uncertainty's SCF-energy term uses max(energy_tolerance, loosest scan threshold used). For a strict caller (reference) the scans are unchanged bit for bit (standard at 1e-9 Ha unverified, strict fallback). `pulay_assessment` records `scan_profile` (`standard_verified` or `standard_then_strict`), `scan_thresholds_ha` (per scan; null = strict fallback) and `scan_energy_resolution_ha`. The final tensor is always computed from the caller's verified (or certified) state.
- `relax` in `cell` and `ions_cell` modes: `single_path.status = "applied"`; every ionic/cell step (including basis rebuilds and final rebuilds) runs the standard SCF with verification; per-frame `verification` as in ONEPATH-1; Pulay/basis-set handling (frozen Miller chart, rebuilds, Pulay assessment) unchanged; `verify = "off"` is an input error. The `stress` and `stress (variable-cell relaxation)` strict fallbacks are removed.
- Still strict (`not_applicable`): spin, Fermi-Dirac, `locking = "auto"` (also with stress), observe/agent and non-run commands; standard-only keys there stay input errors. Engine default (`ScfOptions::default()`) stays strict.
- `BAANDI_REFERENCE_STRICT=on`: unchanged strict reference for stress runs and variable-cell relaxations (the stress block gains only the additive `pulay_assessment.scan_*` keys).
