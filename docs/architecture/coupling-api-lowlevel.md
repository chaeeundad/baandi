# Low-level numerical coupling API

Status: **Designed**, semantic v1.0 only. All external interfaces below await implementation; physics explicitly marked **Deferred** must be rejected. Builds on [scientific coupling](scientific-coupling.md), [coupling physics](../research/coupling-physics.md), [workflow types and gaps](workflow-api.md) and ADR 0017. P11R D3 `CoupledRequest/Response`, `FieldTerm`, `QualifiedObservable` and `EnergyTerm` are the envelope, not duplicated here. This does not claim QM/MM, DFT-CES package compatibility or embedding support.

## Typed fields, grids and basis

**Designed.** Common Id/Digest/Version/Availability rules are those of the workflow API. `FieldRef` consists of `schema_version`, `field_id:Id`, `role:FieldRole`, `array:ArrayRef`, `grid:GridSpec`, `source:SourceSpec`, `environment_digest:Digest`, `state_id:Id|null`, `state_version:u64`, `reference:PotentialReference`, `boundary:BoundarySpec`. State ID is absent for externally supplied fields, with source identity mandatory. No bare numeric array is a valid field.

| `FieldRole` | Unit and sign | Meaning |
| --- | --- | --- |
| `ElectronPotentialEnergy` | Ha | Scalar U added to the electron Hamiltonian |
| `ElectrostaticPotential` | Ha/e | Potential phi for a positive unit charge; q_e=-1, U=-phi in atomic units |
| `ElectronNumberDensity` | electron number/Bohr^3 | n >= 0 apart from the existing XC-specific numerical policy; integral n = N_e |
| `SignedChargeDensity` | e/Bohr^3 | Positive is positive charge; electron contribution is -n |
| `ElectricField` | Ha/(e Bohr), Cartesian vector | E=-grad phi, never grad U with an implicit sign |

`GridSpec` fields: `cell_columns_bohr:f64[3][3]`, `origin_bohr:f64[3]`, `shape:u64[3]`, `periodic:bool[3]`, `layout:C`, `frame:cartesian_lab`, `fft_convention:baandi_positive_inverse_v1`, `sample_location:nodes`, `grid_digest:Digest`. Scalar shape is [n1,n2,n3]; vector shape [n1,n2,n3,3] with Cartesian component fastest. Node r=o+A(i/n1,j/n2,k/n3); scalar flat index `(i*n2+j)*n3+k`. Omega=abs(det A). Unsupported layout/shape, inconsistent cell or misaligned origin fail; no implicit interpolation, rotation, transpose or renormalization.

For phase coordinates x=r-o, `f_G=(1/Ngrid) sum_r f(r) exp(-iG.x)` and `f(r)=sum_G f_G exp(+iG.x)`. Thus `sum_r |f|^2=Ngrid sum_G |f_G|^2` and integration weight is Omega/Ngrid. B=2*pi*A^-T; even-axis Nyquist is labeled negative. An origin translation changes Fourier phase and must be explicitly transformed with a recorded transfer plan. Current native grid has origin zero; nonzero-origin import is a future adapter conversion, not a current flag. Resampling requires a separately validated map, source/target digests, conservation and aliasing-loss report; otherwise reject.

`BasisSpec`: `basis_digest:Digest`, `grid_digest:Digest`, `k_fractional:f64[3]`, `g_miller:i64[NPW][3]`, `cutoff_ha:f64`, `ordering_id:Id`, `normalization:unit_coefficient_norm`. Per-k basis order is explicit, never guessed from dimension. `psi_nk=Omega^-1/2 sum_G c_nk(G) exp(i(k+G).r)`, sum |c|^2=1. Density uses normalized k weights and occupations. Coefficients are dimensionless complex128; Hamiltonian application produces Ha times coefficients. Grid Fourier normalization is not wavefunction normalization.

`PotentialReference = MeanZero | ExplicitMean{value:f64,unit:Ha/Ha_per_e} | Vacuum{reference_id:Id}`. Vacuum references are **Deferred**; a reference shift is a model change and affects eigenvalues. `SourceSpec` names `source_id`, `representation:electron_valence/signed_grid/point_smeared/reconstructed_total`, `source_digest`, `core_convention:Id`, `net_charge_e:f64`, `smearing_recipe_ref:Id|null`. Point-smearing and reconstructed-total export are **Deferred**. Current Hartree takes electron number density, removes G=0 and is not a signed-charge Poisson API. The electron-only electrostatic potential is -V_H, not V_H. V_eff includes XC and pseudopotential physics and must never be exported as phi. Full QM electrostatics needs explicit ionic/core/source reconstruction first.

## Boundary and physical term validation

**Designed** `BoundarySpec` is tagged `PeriodicNeutral{reference,neutrality_tolerance_e:f64}`. Proposed future variants `PeriodicBackground{background_model_id}`, `SlabCorrected{axis,correction_id}`, `Isolated{solver_id}` are **Deferred** and rejected, as are uniform electric fields. Periodic scalar fields do not implement uniform electric fields. The actual QM model remains neutral with an even electron count and supported insulating occupations. Source neutrality and QM neutrality are checked separately; combined neutrality cannot authorize a charged QM subsystem. Tolerances must be finite nonnegative and justified by measured integration noise, not caller permission to change charge. Signed sources with nonzero mean cannot use an unmodified periodic Poisson solve.

`TermSpec`: `term_id:Id`, `identity_digest:Digest`, `field:FieldRef`, `dependencies:{density:bool,geometry:bool,time:bool}`, `consistency:FixedLinearEnergy|Variational{functional_id:Id,quantity:energy/free_energy}|PotentialOnly`, `energy_owner:electronic/environment`, `derivative_provider_ref:Id|null`. Initial implementation target is frozen periodic local scalar fields only. Each outer update creates an immutable environment and a new inner request. Density-dependent, nonlocal, time-dependent and geometry-following terms are **Deferred** until their functional and derivative contracts pass validation; flags cannot imply otherwise.

## Energy and derivative ownership

**Designed**, with derivative implementation **Deferred**. Ledger entries extend P11R `EnergyTerm` with `term_id:Id`, `scope_id:Id`, `source_request_id:Id`, `included_in_band_sum:bool`, `derivative_status:Availability`, and `required_for_total:bool`. Exactly one owner supplies each physical contribution; assembly validates uniqueness, required coverage, functional, reference and environment identity. A complete list is determined by the chosen coupling method, not merely the entries that happened to arrive. A ledger reports `electronic_partial`, `coupled_total` or explicitly named free energy; missing pieces forbid the latter two.

For a frozen electrostatic environment: E=E_KS + integral n U + sum_I Z_I phi(R_I) + E_env. Electron-source cross energy has no factor 1/2; environmental self-energy is distinct. Electronic owner supplies integral n U, environment/driver supplies ion-source and source self terms by an explicit ownership plan. Since eigenvalue sums already include U, the band-form assembler must not add the cross term again. Compare direct and band forms on the same density; retain existing local-zero-mode treatment exactly once. Constant energy terms do not enter H.

For a variational F_emb[n], U=delta F_emb/dn. Integral n U is generally not F_emb; the reconstruction replaces the input-potential contribution by `-integral n_out U[n_in] + F_emb[n_out]`. This is an accounting requirement, not an implemented density-dependent capability. Potential-only terms may yield electronic diagnostics/frozen-field partial energy, never conservative coupled forces or a coupled variational total.

Future derivatives use F=-dE/dR and the workflow stress sign. Fixed phi has ionic force -Z_I grad phi(R_I). Geometry-dependent U requires -integral n dU/dR, plus all environment, ion and constraint/link-atom derivatives. Stationarity may remove response terms only when the actual coupled functional and both solves justify it. Stress also needs cell dependence, reciprocal/grid transformations, basis/Pulay and environment terms at stated constraints. No missing derivative is zero-filled. A QM/MM driver must enumerate exclusions, link atoms, charge redistribution and partition terms with owners before asking for totals; none is supplied by this design.

## Apply-only operator lease

**Designed** semantic operations: `lease_operator(calc_id, state_version, k_index) -> OperatorLease` and `apply(lease, x:ComplexBuffer, y:MutableComplexBuffer) -> Result<(),OperatorError>`, plus block apply. The existing **Implemented** internal `LinearOperator::{dimension,apply,apply_block}` in `dft-solvers/src/lib.rs` and `Hamiltonian` in `dft-physics/src/hamiltonian.rs` are building blocks, not exported session access.

`OperatorLease` carries `lease_id:Id`, `generation:u64`, `calc_id`, `state_version`, `model_digest`, `environment_digest`, `basis:BasisSpec`, `dimension:u64`, `hermitian:true`, `capabilities:{block_apply:bool,concurrent_apply:bool}`, `owner_token:Id`. It is a frozen-density H at one k; not a nonlinear SCF map, density response Jacobian, explicit matrix or transferable pointer. Mutating/rebuilding the potential is forbidden while borrowed. Alternatively a separately owned immutable snapshot may outlive the session only if its storage budget is granted. Release invalidates the handle; generations prevent reuse after free. No implicit lease across a step, checkpoint restore or environment update.

Caller owns preallocated x/y; lengths and basis match, x and y cannot alias, x is read-only, y is completely overwritten on success. On failure y is invalid and cannot be consumed. Core retains scratch/plans and their locks. Default lease is serial: underlying FFT scratch need not be reentrant even when apply takes a shared receiver. Concurrency requires separately provisioned scratch and an advertised tested capability. A pinned read-only lease retains all required owners; cancellation/release waits for an active call to complete, never frees live memory. IPC uses an opaque lease ID and binary batches, never raw pointers. External eigensolvers still need residual/orthogonality/occupation checks and the normal SCF certificate; arbitrary external solver success cannot certify the calculation.

## Callback and array transport contract

**Designed.** Callbacks are classified, not general executable hooks. Read-only progress callbacks occur after complete steps in adapters. Environment-solver calls occur between complete inner solves, producing a new request. An in-process native eigensolver can consume a frozen apply-only operator; it cannot change its potential during a solve. A future pure deterministic variational field evaluator may run at a mathematically specified density evaluation point only after its functional derivatives, repeatability, cost and reentrancy are validated; this class is **Deferred**, not a Python callback slot. No LLM, HTTP, network, file I/O, JSON serialization or foreign scripting callback is allowed inside Hamiltonian, FFT, eigensolver or density hot loops.

In-process exchange prefers borrowed immutable contiguous arrays with explicit owner and bounded lifetime, not a promise that every conversion is zero-copy. A writable destination has exclusive ownership. Cross-process local exchange may use shared memory with descriptor bounds and producer/consumer leases; otherwise use binary IPC with bounded frames. `BufferDescriptor` fields: `buffer_id:Id`, `generation:u64`, `dtype:f64le/complex128le`, `shape:u64[]`, `strides_bytes:u64[]`, `offset_bytes:u64`, `byte_length:u64`, `alignment:u64`, `role`, `units`, `owner_id:Id`, `access:read_only/exclusive_write`, `completion_token:Id`, `payload_sha256:Digest|null`. Validate overflow, span, alignment, dtype/endian and quotas before creating a view; nonnative endian or layout requires an explicit recorded copy. Complex values interleave real/imaginary. Consumer acquires only after producer completion; producer cannot reuse until all consumers release. Shared writable arrays cannot change during validation or use. Hash immutable IPC/artifact payloads at the boundary; do not rehash per apply. Process crash invalidates leases and yields failure, never partial success.

P11R `ArrayRef` remains the durable representation (binary payload plus small manifest); `BufferDescriptor` is an ephemeral borrow, not a second checkpoint format. JSON is permitted for small manifests/control outside loops, never array elements. IPC frames include negotiated version, request/field ID, shape/type, length and checksum; incomplete/corrupt frames fail. Binary transport and concrete ABI implementation are **Deferred**. GPU/device handles and synchronization are **Deferred**; CPU semantics do not assert host-readable GPU memory. Human-facing field exports should use standard cube/XSF first under the repository output policy, with complete metadata retained; no new writer is implemented here.

## Inner and outer completion

**Designed.** Inner status comes only from the engine certificate. `OuterCertificate` contains `coupling_method_id:Id`, `functional_id:Id`, `request_ids:Id[]`, `environment_digests:Digest[]`, `iteration:u64`, `criteria:{name:Id,residual:f64,unit:Id,threshold:f64}[]`, `inner_certificate_refs:Id[]`, `passed:bool`. Driver must define physically meaningful coupled residuals and all required inner solves; tiny changes in one scalar energy alone do not establish coupled stationarity. Each criterion records units and positive threshold. Empty criteria, stale inner results or mismatched environment identity fail. No outer certificate is currently available.

## Mandatory gate before any QM/MM or conservative coupling claim

**Designed test plan; no results claimed.** Freeze fixtures, independent expected values, displacement/strain sweeps and measured noise budgets before implementation acceptance. Include cubic/skew/elongated/slab-like periodic cells, multiple atom counts, Gamma/k meshes, band counts, insulating gaps and projector structures. A slab-like periodic fixture does not validate open/slab-corrected boundaries. Keep >10 s debug cases ignored with documented release commands. Never relax thresholds after a failure.

| Gate | Required tests and acceptance evidence |
| --- | --- |
| Baseline/zero field | Existing regression suite; same input/build/threads yields bit-identical density, energy, history and certificate with absent/zero coupling |
| Units/sign/gauge | Both signs of phi/U; electron-only U0 shifts eigenvalues +U0 and energy +N_e U0 with unchanged density/projector; phi0 shifts electronic energy -N_e phi0 and ionic +sum Z phi0; neutral total unchanged |
| Grid/basis | Fourier modes, Parseval, charge quadrature, row/column and translated-origin transforms, skew/left-handed cells, negative Nyquist and alias rejection; per-k basis mismatch rejected |
| Boundary/Poisson | Analytic neutral signed-source Fourier solutions, positive source sign, G=0 reference; reject net charge, bare singular charges and all unsupported boundary variants; finite-size/boundary convergence for any later enabled model |
| Energy consistency | Direct/band agreement within measured residual bound; cross energy once without 1/2; zero-mode, environment constants and self-energy counted once; missing/duplicate ledger owners rejected; weak-field derivative dE/dlambda=integral n W |
| Force consistency | Central differences of the complete stationary total versus every QM and MM component over several step sizes; include environment response, geometry-following fields, link atoms/exclusions; translation and equal/opposite interaction checks when the full closed system is invariant (not for an anchored external field) |
| Stress consistency | Symmetric strained-cell energy differences with explicit fixed-fractional constraints; include basis/Pulay, field and environment derivatives; verify sign, shear factors and pressure relation |
| Coupling convergence | Independent solvable coupled functional, separate inner/outer residual sweeps; prove stationary energy/derivatives and no reuse of stale fields; failure/cancellation and nonvariational cases never report coupled success |
| Operator/lifetime | Hermiticity, reference apply and block equality, residual/orthogonality checks; reject wrong k/basis/generation, aliasing and released handles; concurrency/crash and ownership tests |
| Transport/identity | Binary round trip and count integral; truncated, corrupt, oversized, stale, wrong-unit/reference/model payload rejection; idempotency/conflicts; immutable shared-memory lease and restart downgrade rejection |

**Not claimed:** working QM/MM, DFT-CES compatibility, conservative forces/stress, charged cells, open boundaries, polarizable embedding, electrostatic reconstruction, performance improvement, exact external restarts or an interoperable binary ABI. Every enabled combination needs its own validation evidence and capability update.
