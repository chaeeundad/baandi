PHYSICS_CONVENTIONS (implement exactly; append them to docs/physics-conventions.md):
1. Real-space density n(r) is a real array on the FFT grid (Array3<f64> or complex with zero imaginary part; your choice, justify). Its reciprocal coefficients n(G) = to_reciprocal(n(r)) so that n(r) = sum_G n(G) exp(iG.r) and n(G=0) is the mean density.
2. Orbitals: psi_b(r) = Omega^(-1/2) * to_real(scatter(c_b))(r), sum_G |c_b(G)|^2 = 1. Density n(r) = sum_b f_b |psi_b(r)|^2 with occupations f_b (2 for doubly occupied). Check: (Omega/N) sum_r n(r) = sum_b f_b.
3. Kinetic energy T = sum_b f_b sum_G 0.5*|G|^2 |c_b(G)|^2 (Hartree).
4. Hartree: V_H(G) = 4*pi*n(G)/|G|^2 for G != 0 and V_H(G=0) = 0 (explicit zero convention; document that the divergent G=0 contributions of Hartree, local pseudopotential and Ewald are handled together later via the alpha-Z term). E_H = 0.5 * Omega * sum_{G != 0} 4*pi*|n(G)|^2/|G|^2. V_H(r) = to_real(V_H(G)). The sum runs over all FFT-grid frequencies that the grid represents (state how Nyquist components of even grids are treated: use the grid's frequency rule; mention that components outside the density sphere are the caller's responsibility).
5. LDA-PZ in Hartree atomic units. rs = (3/(4*pi*n))^(1/3). Exchange (Slater, alpha = 2/3): eps_x = -(3/4)*(3/pi)^(1/3) * n^(1/3), v_x = (4/3)*eps_x. Correlation PZ81, unpolarized: for rs >= 1: eps_c = gamma/(1 + beta1*sqrt(rs) + beta2*rs) with gamma = -0.1423, beta1 = 1.0529, beta2 = 0.3334; for rs < 1: eps_c = A*ln(rs) + B + C*rs*ln(rs) + D*rs with A = 0.0311, B = -0.048, C = 0.0020, D = -0.0116. v_c = eps_c - (rs/3) * d(eps_c)/d(rs) (derive and state it; do not rely on memory of a printed formula, verify by finite differences). v_xc = d(n*eps_xc)/dn. Density threshold: for n <= 1e-10 set eps_xc = v_xc = 0 (our documented choice, chosen to match QE's treatment of vanishing density; P6 will check). Negative or non-finite densities are a typed error except tiny negative values from roundoff above a stated magnitude, which are treated as zero (state the rule and test it). E_xc = (Omega/N) sum_r n(r)*eps_xc(n(r)); also return the double-counting integral (Omega/N) sum_r v_xc(r)*n(r).
6. Ewald ion-ion energy for point charges Z_I at positions r_I in a periodic cell, with a uniform neutralizing background and the standard convention that includes the background term -pi*(sum Z)^2/(2*Omega*eta^2) and the self term -(eta/sqrt(pi))*sum Z_I^2: E = 0.5*sum_{I,J} Z_I Z_J [ sum_R' erfc(eta*|r_IJ+R|)/|r_IJ+R| ] + (2*pi/Omega) sum_{G != 0} (exp(-G^2/(4*eta^2))/G^2) |sum_I Z_I exp(iG.r_I)|^2 - (eta/sqrt(pi)) sum Z_I^2 - pi*(sum Z)^2/(2*Omega*eta^2), where the primed sum excludes R = 0 when I = J. State the convention in the doc and compare it to the QE output term "ewald contribution" in a P6 note (do not claim agreement now). Choose eta and the real/reciprocal cutoffs from a stated error control (for example target 1e-12 relative to |E|) and implement the shell enumeration from the lattice bounds with a justified bound (as done in dft-basis).
