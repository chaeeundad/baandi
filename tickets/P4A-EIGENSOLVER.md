TASK_ID: P4A-EIGENSOLVER
GOAL: Build the eigensolver stack independent of any physics: (1) a thin dense linear-algebra adapter over faer in dft-numerics (Hermitian eigendecomposition, complex GEMM, orthonormalization); (2) in dft-solvers, a LinearOperator abstraction, a dense baseline eigensolver, and a matrix-free block Davidson solver with a preconditioner trait, restart, residual-based convergence, and explicit failure reporting. Verified against dense references on synthetic Hermitian matrices.

DESIGN REQUIREMENTS (record the API and reasons in docs/decisions/0006-eigensolver-api.md):
1. dft-numerics: column-major `ComplexMatrix` (rows, cols, Vec<Complex64>, element (i,j) at i + j*rows). Functions: `hermitian_eigh(&ComplexMatrix) -> Result<(Vec<f64> ascending, ComplexMatrix eigenvectors)>` (checks squareness and Hermiticity within a stated tolerance, typed errors), `gemm` with options for identity/conjugate-transpose of each operand, and an `orthonormalize` routine for a block of column vectors against optional already-orthonormal columns that reports and drops numerically dependent columns below a stated threshold (use two-pass Gram-Schmidt or faer QR; justify the choice).
2. dft-solvers: `LinearOperator` trait (dimension, `apply(&self, x, y)` for one vector, `apply_block` with a default loop over columns), Hermitian by contract. `Preconditioner` trait (apply to a residual block) plus a diagonal preconditioner built from a diagonal estimate (the kinetic energy 0.5*|G|^2 in later use) with a stated safe denominator rule.
3. `DenseEigensolver`: forms the explicit matrix by applying the operator to unit vectors (guard against large dimension with a typed error and a documented limit), then calls hermitian_eigh. It is the oracle for tests and the P3 Hermiticity check.
4. `Davidson`: block Davidson for the lowest `bands` eigenpairs. Parameters: tolerance on the residual 2-norm per band (absolute, same units as the eigenvalue), max_iterations, max_subspace (restart when exceeded, keeping the current Ritz vectors), block size, seed, optional initial guess block, optional preconditioner. Rayleigh-Ritz in the subspace via hermitian_eigh. Must: keep the subspace orthonormal (drop dependent corrections), handle exactly degenerate and near-degenerate eigenvalues without missing a copy, never return unconverged results silently: on failure return `SolverError::NotConverged` carrying iterations, the max residual, and per-band residuals; on success return eigenvalues ascending, eigenvectors (column-major block), per-band residual norms, iteration count, and a per-iteration history vector of (max residual) for diagnostics. No logging, file I/O, or JSON inside the numerical loop.
5. No value-dependent shortcuts: a previous review rejected code that special-cased inputs to satisfy tests. Convergence must come only from computed residuals.
TESTS (all in the crates, tolerances stated in code and printed measured values with --nocapture; no test over about 10 s in debug; anything larger goes behind #[ignore] with a documented `cargo test --release -- --ignored` command):
a. numerics: hermitian_eigh on the 2x2 [[2, 1-i],[1+i, 3]] (eigenvalues 1 and 4, 1e-12), on a 4x4 built as U D U^H from a fixed Fourier unitary (recover D to 1e-12), on a random seeded Hermitian N=60 (residual and orthonormality < 1e-10), rejection of a non-Hermitian matrix, gemm against a naive loop including the conjugate-transpose option (1e-12), orthonormalize drops a duplicated column and returns orthonormal output (1e-12).
b. solvers, using small `LinearOperator` implementations in test code: a diagonal operator with known eigenvalues; the 2x2 and 4x4 cases above through both the dense solver and Davidson; a random Hermitian N=200 with bands=8: Davidson vs dense eigenvalues < 1e-9, residual < tolerance, orthonormality < 1e-10, Hermiticity of the operator itself checked by <x|Hy> = <Hx|y> with random x, y (1e-12 relative); a DFT-shaped matrix N=300 (diagonal 0.5*(k^2) growth plus small random Hermitian coupling, with the diagonal preconditioner) where preconditioned Davidson converges in fewer iterations than unpreconditioned (assert and print both counts); an exactly 3-fold degenerate lowest level (bands=3 must return all three, bands=2 must be consistent); a near-degenerate pair separated by 1e-6; a case that cannot converge within max_iterations returns NotConverged with diagnostics (not a panic, not Ok); a restart case with a deliberately small max_subspace; determinism: same seed gives bitwise-identical results, different seed gives eigenvalues equal within tolerance.
