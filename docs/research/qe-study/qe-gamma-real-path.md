## 0. The one fact to keep in mind
The QE comparison runs recorded for BAANDI used `K_POINTS automatic 1 1 1`, which in QE is the complex k-point code at k=0. QE's real Gamma path (`K_POINTS gamma`) was never the comparison target. Everything below is additional speed that QE has at Gamma and BAANDI does not, on top of the measured gap. By the counts in section 7, QE's real path should be about 1.7 to 2.3 times faster than its own complex k=0 run on a case like the 8-atom cell (estimate, to be measured on dev08 before any claim; hypothesis H0).

## 1. The mathematical basis
At k=0 with a real local potential, a real-valued nonlocal projector structure (real spherical harmonics times the factor (-i)^l, structure factor exp(-iG.tau)), and no magnetic field or spin-orbit coupling, the Hamiltonian commutes with complex conjugation of the wavefunction. Hence every eigenspace has a basis of real-valued functions psi(r). For psi(r) = Omega^(-1/2) sum_G c(G) exp(iG.r) this means exactly

c(-G) = conj(c(G)) for all G in the sphere.

Consequences:
1. Only the half sphere (one of each +-G pair, plus G=0) is stored. For the 8-atom cell: 2969 coefficients on the full sphere become 1485 complex numbers (G=0 once, 1484 pairs). The number of real degrees of freedom of a normalized state is 2969 either way (G=0 contributes 1 real number because its imaginary part is zero; each of the 1484 stored G contributes 2).
2. The projectors obey the same symmetry. With beta(G) = (-i)^l f(|G|) Y_lm(G-hat) exp(-iG.tau), the parity Y_lm(-G-hat) = (-1)^l Y_lm(G-hat) gives beta(-G) = conj(beta(G)). For odd l the radial transform vanishes at G=0, so the G=0 projector value is real (zero or the l=0 value). Precondition for BAANDI: its projectors use real spherical harmonics (they do: `real_spherical_harmonic` in `dft-physics/src/hamiltonian.rs`).
3. Inner products. For two real-structured states a and b with the full-sphere sum over G:
   <a|b> = sum_{G in full sphere} conj(a(G)) b(G) = 2 Re sum_{G in half, G != 0} conj(a(G)) b(G) + a(0) b(0).
   It is a real number. Written with all half-sphere entries: twice the real dot product of the two arrays seen as real vectors of length 2*N_half, minus the product of the two G=0 values (the G=0 term was counted twice and has no imaginary part). This correction is what QE applies after every product, as a rank-one update of the result of the real matrix product. The same formula covers norms, the overlap and Hamiltonian reduced matrices, the projections on projectors, the orthogonalization coefficients, and the residual norms.
4. Matrix products that rotate states (new vector = sum of old vectors times coefficients) are applied with REAL coefficients to the half-sphere array seen as a real array; no G=0 correction is needed because the result is again real-structured.
5. The reduced Davidson problem is a real symmetric (or real symmetric-definite generalized) problem, solved with a real dense solver (QE: the real generalized routine in `LAXlib/rdiaghg.f90`, built on the LAPACK symmetric-definite drivers). For an orthonormal basis (BAANDI) it is a plain real symmetric problem.

## 2. Plane-wave set and memory layout in QE
1. G-vector generation (`ggen` in `Modules/recvec_subs.f90`) loops over the first Miller index from 0 upward, over the second from 0 upward on the plane where the first is 0, and over the third from 0 upward on the line where the first two are 0. The sphere is therefore cut at the level of the integer triples, not by a Cartesian sign. G=0 is first in the list (this is why a start index of 2 identifies the "has G=0" process in parallel runs). The wavefunction set at k=0 is a prefix of this list sorted by |G|^2, so the same prefix property holds as in the complex case.
2. The FFT descriptor builds a second index table that maps every stored G to the grid position of -G (`fft_set_nl` in `FFTXlib/src/fft_ggen.f90`). The stick sets of the descriptor are made symmetric: for every stick in the half sphere the mirrored stick is also marked, so the FFT sees the full-sphere stick pattern (`stick_base.f90`, `fft_types.f90`). Consequence: QE's pruning (sticks, active columns) is unchanged by the gamma trick; what shrinks is the stored vector and the products, not the transform's support.
3. The plane-wave count is `(N_full + 1)/2` on both the wavefunction and density descriptors.
4. Wavefunctions, H times wavefunctions, and projector tables stay declared complex, with the same leading dimension as the complex code; the real matrix routines are called on the same memory with twice the row count (real and imaginary parts interleaved, which is the natural complex layout). No data is converted or copied. A real vector therefore occupies 2*N_half doubles contiguous, G=0 first, with its imaginary part held at exactly zero.
5. The density grid and the potential grid also use the half sphere in G space (density and potentials are real in r-space). The G-space density has N_half entries. QE does not use real-to-complex transforms for these grids: it fills the full-sphere pattern using the same -G table and runs the complex transform, and takes the real part (`Modules/fft_rho.f90`). Only the G-space bookkeeping (Hartree, local potential, structure factors, mixing) is halved.

## 3. Hamiltonian application in the gamma path (`h_psi`, `vloc_psi_gamma_acc`)
1. Kinetic: the diagonal multiplication on the half sphere; padding beyond the true length is zeroed.
2. Local potential, two bands per transform. For bands a and b (both real-structured) the routine forms on the FFT grid the function with coefficients
   phi(G) = a(G) + i b(G) for G in the half sphere, and phi(-G) = conj(a(G) - i b(G)).
   Because a and b are real-structured, phi(-G) is exactly the coefficient that the full-sphere sum of a(G) + i b(G) would carry at -G, so phi is the full-sphere vector of the complex function psi_a(r) + i psi_b(r) with psi_a, psi_b real. One inverse transform gives both real functions: the real part is psi_a(r), the imaginary part is psi_b(r). The multiplication by the real potential V(r) acts on both at once, and one forward transform gives h(G) = FT[V psi_a + i V psi_b]. The two results are separated by the parity decomposition
   (V psi_a)(G) = (h(G) + conj(h(-G)))/2,  (V psi_b)(G) = (h(G) - conj(h(-G)))/(2i),
   which QE evaluates only on the half sphere. At G=0 the two table entries coincide, so the double write of the scatter and the double read of the gather are harmless.
3. An odd band count has one leftover band: it is scattered alone with the same Hermitian completion, transformed, and the half-sphere values are read directly (no separation needed since the result is automatically real-structured).
4. Cost: for m bands, ceil(m/2) inverse and ceil(m/2) forward transforms, i.e. exactly half the transforms of the complex code. The grid size, the sticks and the pruning are the same as in the complex path. The potential multiply, the scatter and the gather are also done once per pair.
5. Nonlocal term: the projector table (nkb columns, half sphere) is multiplied with all bands at once as a real matrix product with inner dimension 2*N_half, scaled by 2, followed by the G=0 rank-one correction (`calbec_gamma` in `Modules/becmod.f90`; a matrix-vector variant when a single band is applied). The coupling matrix (small, real per atom, block nh by nh) is applied per atom by small real matrix products to the projection coefficients, and the back-application is ONE real matrix product (half-sphere rows times 2, nkb inner, m columns) accumulated into the output (`add_vuspsi_gamma`). The projections are real numbers, not complex, so their storage is also halved.
6. At the end of the whole application the imaginary part of the G=0 output coefficient of every band is set exactly to zero. This is a safety measure against drift: no operation in the chain can make it nonzero analytically, rounding could.

## 4. The real Davidson (`regterg`) versus the complex one (`cegterg`)
The algorithm (note 1) is unchanged; only arithmetic differs.
1. All basis vectors, their H products (and S products when ultrasoft) are half-sphere arrays treated as real arrays. All the dense products of the Davidson loop use the real matrix routine with inner dimension 2*N_half and the factor 2 plus the G=0 rank-one correction: the initial reduced matrices, the update with the new vectors, the formation of correction vectors from the Ritz coefficients (real coefficients, no correction needed), the final contraction to the new eigenvectors, the restart contraction of basis and H products.
2. The reduced matrices are real symmetric. Only one triangle is computed and the other triangle copied; the complex code does the same with conjugation.
3. Vectors are normalized with the weighted norm of item 3 of section 1, after the preconditioner. The G=0 coefficient of every new vector has its imaginary part set to zero explicitly after normalization and at entry.
4. The convergence rule, subspace capacity (nvecx = 2 times bands by default), restart and preconditioner are exactly the complex ones. The preconditioner is a real diagonal function of the plane wave; it acts on the half sphere unchanged.
5. QE at Gamma only calls the real code (`diag_bands_gamma` in `c_bands.f90` selects it for Davidson, conjugate gradient, ParO and RMM). The initial subspace rotation also has a real variant.
6. Iteration counts: QE's gamma and complex-k=0 runs have similar SCF iteration counts in the recorded outputs (the relayed 8 to 11 iterations are for the complex k=0 run; I have no QE gamma run). Theory suggests the Davidson convergence per iteration is not worse in the real path: per FFT pair the real path contributes two real directions, which span two complex directions of the complexified space, against one complex direction of the complex run. To be verified on BAANDI.

## 5. Density (`sum_band_gamma` and the helper that accumulates it)
Two bands are transformed together, with the same packing as in section 3 (inverse only). Since the real part of the result is psi_a(r) and the imaginary part psi_b(r), the density increment is w_a Re(.)^2 + w_b Im(.)^2 with w = occupation weight divided by the cell volume. Bands are visited in adjacent pairs; an odd last band is transformed alone and its weight is used for both parts of the combined function (the imaginary part of the single-band transform is exactly zero in exact arithmetic). The transform count is ceil(m/2) per spin and k. No symmetrization is applied at the gamma path in the density step (the symmetrization call is guarded by the k-point code). After the grid accumulation the density goes to the half-sphere G representation through one transform. Bands with negligible weight are not skipped in this routine (the QE-side band-type flag only changes Davidson thresholds).

## 6. What the G=0 treatment amounts to (a checklist)
1. The G=0 imaginary coefficient is exactly zero at entry to Davidson, after every normalization, and at the output of the Hamiltonian application.
2. Every real-GEMM-based inner product is corrected by subtracting the G=0 product once (rank-one update). Alternative that avoids the correction: store the G=0 coefficient multiplied by 1/sqrt(2) in the working vectors so that a plain doubled real dot product is exact; every operator that consumes it (scatter for the FFT, kinetic, projections) must then use the unscaled value. QE does not do this; it is an optional micro-design (H9).
3. G=0 is the only index that is its own mirror; in the pair packing the double write and double read at that index are consistent.
4. Projector products at G=0: real; for odd l they vanish.

## 7. Estimated gains for BAANDI at Gamma (derived counts, estimates only)
Reference case: the 8-atom Si cell, Ecut 30 Ry (15 Ha), 2969 plane waves on the complex sphere (1485 on the half sphere), 36^3 FFT grid (N_g = 46656), 20 bands, 4 projector channels per atom (32 columns in total). Assumed Davidson shape: block of c = 20 new vectors added to a basis of size m between 20 and 60 (the exact BAANDI shape is in `dft-solvers`; the capacity scales with the band count). Flops are counted as 8 per complex multiply-add and 2 per real one.

### 7.1 FFT
- Full 3D complex transform on 36^3: about 5 N_g log2(N_g) = 5 x 46656 x 15.5 = 3.6 Mflop (rustfft measured 0.30 ms for the full inverse on this grid in the ledger, i.e. about 12 Gflop/s). The pruned fused path in the ledger removes about 40 percent of the flops: about 2.2 Mflop per transform, so about 4.3 Mflop per Hamiltonian application (inverse plus forward).
- Complex path: one inverse and one forward transform per vector. Gamma real path: one pair per two vectors. Per block of 20 vectors: 86 Mflop becomes 43 Mflop. FFT work per vector halves. Pack and unpack per pair cost about 2 x N_full words of copy and about 6 flops per G (about 20 kflop per pair), negligible against 8.6 Mflop.
- The ledger's si8 SCF has about 2416 Hamiltonian vector applications per SCF (T=1 total 3.42 s, i.e. 1.4 ms per vector application including everything). With 2 transforms at 0.3 ms (unpruned) to 0.2 ms (pruned) the FFT is 0.4 to 0.6 ms of the 1.4 ms per vector: about 30 to 40 percent of the SCF.
- Density: 16 occupied plus 4 empty bands means 20 inverse transforms per SCF iteration in the complex path (the ledger forbids skipping empty bands in the complex path because it would change bits), 10 in the real path; the weighted square costs 3 flops per grid point per band (0.14 Mflop), negligible.
- Result: FFT component about 2.0 times faster (the exact factor is two minus the pack overhead, about 1.95 to 2.0).

### 7.2 Dense products (GEMM family: reduced-matrix update, orthogonalization, correction assembly, rotation, restart contraction)
- One product of an N-row block with an m by c coefficient or Gram matrix: complex 8 x 2969 x m x c = 23.8 kflop per (m c); real with inner dimension 2 x 1485 = 2970: 2 x 2970 = 5.9 kflop per (m c). The ratio is 4.0 (plus the rank-one G=0 correction, 2 flops per element of the m by c result, negligible for the shapes here). The G=0 correction replaces about 0.03 percent of the product.
- With m = 40 and c = 20 as a representative step, my accounting of the BAANDI Davidson step (incremental Gram update 8 N c (m + c); two orthogonalization passes at 4 x 8 N m c; correction assembly 16 N m c) gives about 28 + 76 + 38 = 143 Mflop complex per block, about 36 Mflop real.
- Memory traffic per block product: complex 47.5 KB per vector (2969 x 16 B), real 23.8 KB. For (m + c) = 60 vectors read once each, 2.85 MB complex against 1.43 MB real per product. Arithmetic intensity: complex 0.5 m c/(m + c) flop/byte = 6.7 at (40,20); real 0.25 m c/(m + c) = 3.3. Both stay compute-bound while the basis lives in the L2 cache (60 vectors of H and psi: 5.7 MB complex, 2.9 MB real, which fits a performance-core cluster L2 on Apple Silicon and many server L2/L3 slices). When the basis falls out of cache (larger systems), the real path is bandwidth-limited at half the bytes of the complex path, so it wins at least 2 times there and up to 4 times when compute-bound.
- Expected time gain: 3 to 4 times for the GEMM family if the real kernels reach a flop efficiency equal to the complex ones (real GEMM kernels typically reach a higher fraction of peak because they have no complex shuffles); I use 3 to 4.

### 7.3 Nonlocal
- Complex path: projection 8 x 2969 x 32 x 20 = 15.2 Mflop plus back-application equal = 30 Mflop per 20 vectors. Real path: 2 x 2970 x 32 x 20 = 3.8 Mflop plus 3.8 = 7.6 Mflop. Factor 4 in flops.
- Memory: BAANDI today traverses the whole projector table (32 columns x 47.5 KB = 1.5 MB) once per vector for the projection and once for the back-application, so about 3 MB per vector of projector reads; a blocked real matrix product reads the half-sphere table (0.76 MB) once per block of 20 vectors for each of the two operations: about 1.5 MB per 20 vectors against about 60 MB. In the ledger the 8-atom nonlocal step costs 90 microseconds per application, i.e. about 6 percent of the 1.4 ms per vector. Real block product: well under 1 percent. The ledger declined a per-block BLAS rewrite for the complex path because it changes scalar association; the real path has no bit-identity contract with the complex one, so that reason does not apply (H3).

### 7.4 Whole-SCF estimate
Let the fractions of the Gamma SCF at T=1 be (assumed from the ledger numbers above, to be replaced by a measured profile): FFT 0.35, GEMM family 0.40, nonlocal 0.065, density, diagonalization of the small matrices, mixing, setup 0.185. With speed-ups 2.0 (FFT), 3 to 4 (GEMM family), 4 to 8 (nonlocal), 1.0 to 1.2 (rest):
- Time ratio = 0.185/1.1 + 0.35/2 + 0.40/3.5 + 0.065/5 = 0.17 + 0.175 + 0.114 + 0.013 = 0.47, a speed-up of about 2.1 times.
- Range with the pessimistic and optimistic ends of the assumptions: 1.7 to 2.4 times. The remaining non-FFT, non-GEMM part is where the gain stops (Amdahl): the density grid transforms, the Hartree and XC steps, mixing and the small dense solves are not halved by this path except for minor items.
- Memory (Davidson storage): the subspace arrays (psi, H psi for up to the capacity) halve.
- Per-component gain is smallest where BAANDI is least compute-bound (the pruned fused FFT already moves little memory) and largest where it is limited by BLAS-1-like traffic (nonlocal).
All of this is estimate. The only acceptable evidence is the profile and the A/B timing in docs/performance/README.md protocols.

## 8. Design obligations for a BAANDI implementation
1. Isolation: a separate module (real Gamma path) selected by a switch at the engine level; the complex k-point code, its tests and its bit-identical hashes stay untouched. The k-point and shifted-Gamma runs must keep matching `docs/performance/baseline*.json` bit for bit (existing `--require-identical` gate).
2. When it applies: exactly one k point equal to k=0 (reduced coordinates wrapped), unshifted mesh, spin-unpolarized or collinear spin (each channel separately real), norm-conserving, real local potential, no complex-valued external fields, no spin-orbit or noncollinear magnetism, no complex-valued projector convention. It does not apply to a shifted Gamma-containing mesh point, nor to any k != 0 (time reversal maps k to -k, which coincides with k only at the zone-boundary points; see H8 for the speculative extension). The dispatcher must check the condition and fall back to the complex path with a logged reason, never silently approximate.
3. Basis: a half-sphere ordering derived from the existing full sphere: G=0 first, then the representatives with the lexicographically first nonzero Miller index positive; keep the sort by |G|^2 within the same prefix property used by the density sphere truncation. Store the table that maps each half-sphere index to the position of its mirror in the FFT grid (the existing grid indices already give both +G and -G positions since the full-sphere FFT plan is built from Miller triples). The mirror table is the only new index structure.
4. Normalization convention: the same Omega^(-1/2) sum c exp(iG.r) with the weighted norm of section 1 giving sum over the full sphere |c|^2 = 1. All physical quantities (energy, density, eigenvalues, forces if added later) must be expressed through the full-sphere sum, not through the half-sphere sums.
5. Sign and phase conventions with the complex path: a real wavefunction has a gauge freedom of a sign (and an orthogonal rotation inside degenerate subspaces), whereas the complex path has arbitrary phases. No test may compare wavefunction coefficients; compare gauge-invariant quantities only: eigenvalues, total and band-resolved energies, the density, and sums over degenerate subspaces (for example, per-band densities are compared only after summing degenerate bands). Checkpoint, volumetric and band-density writers receive the Hermitian completion of the half-sphere vector (full sphere) so downstream readers and file formats are unchanged. The checkpoint must record which representation was used and the reader must refuse mixing without conversion.
6. Equivalence test against the complex Gamma run: energy and eigenvalues to 1e-12 Ha at a SCF threshold tight enough that the complex run itself is reproducible to better than that (the ledger shows variants agree to about 5e-14 Ha, so the gate is realistic), on at least: Si2 (the R1 case, E = -7.295530468210927 Ha), the 8-atom cell, a skewed and an elongated cell, a multi-projector synthetic fixture (several channels per l), an odd band count (the unpaired band path), a system with an insulating gap and one with empty buffer bands. Density to the same level in the L2 norm. Bit-identity with the complex path is NOT a contract (different arithmetic and association); the previous "density hashes change as expected for an algorithm change" rule of the ledger applies.
7. Unit tests at component level, each against a straightforward complex reference on random real-structured vectors: pair pack and unpack (round trip to 1e-15 relative); paired H application against two single complex applications; the doubled-dot-product formula with the G=0 correction against the full-sphere complex inner product; the half-sphere projection against the complex projection; real Davidson on a small dense real matrix; the odd-band path; the imaginary G=0 part staying exactly zero over many iterations.
8. Determinism across thread counts: the pairing rule must depend only on the column order of the block (adjacent columns: (0,1), (2,3), ...), never on the thread count, the pool state or which bands converged earlier in a way that differs between runs; parallelism by pairs (each task owns whole pairs), with fixed association of every sum. The result for a vector has a dependency on its partner at the level of FFT rounding (the extraction subtracts or adds the partner's mirrored image, errors are of the size of one rounding of the combined function) so partner choice must be a deterministic function of the algorithm state, which it is for a pure block rule. Gamma today runs with one band worker (ledger); with pairs the natural work unit becomes one pair.
9. Real kernels: `dft-numerics` needs a real GEMM entry on half-sphere arrays seen as real (the f64 backend, MKL via the existing adapter for dgemm), the G=0 correction as a separate rank-one update with fixed order, and a real symmetric eigen driver for the small reduced matrix (the faer route is acceptable). None of this touches the complex kernels.
10. Odd and even band counts and block sizes: the unpaired band is handled by the single-band packing; a block of c vectors with c odd uses (c-1)/2 pairs plus one single.
11. FFT plan reuse: the existing fused plan (full-sphere pruned, plane-fused, potential multiply fused) is used unchanged for the pair transform because the pair vector lives on the full-sphere index set; only the pack and unpack are new (these can write directly into the plan's input scatter and read from its output gather). Do not add real-to-complex transforms for the pair path: they would give the same factor 2 with a new code path and the pair packing already exists in QE and is simple.
12. QE evidence: the real path validation against QE must use a QE run with `K_POINTS gamma` (and the complex k=0 run kept as second reference) on dev08 with a real recorded command, version, input and UPF SHA-256 (AGENTS.md rule); the old R1 to R8 comparisons remain valid as independent evidence.
13. README validation block (user rule): after verification extend `scripts/make_readme_figures.py` for the new evidence; do not type numbers.

## 9. Risks
1. Subtle loss of symmetry: any step that breaks c(-G) = conj(c(G)) (a complex random start, a rounding drift in the imaginary part of the G=0 entry, an operator applied to the half sphere with complex coefficients that do not preserve it) yields non-physical states without raising an error. Mitigation: the imaginary part of the G=0 coefficient forced to zero at the same places as QE (section 6), and a debug-only invariant check in tests.
2. Subspace dimension subtlety: a complex Davidson with m complex vectors and a real Davidson with m real vectors have the same nominal subspace dimension; the iteration counts may differ (section 4, item 6). If the real path needs more iterations at equal capacity, part of the gain is lost; the capacity may need to be re-tuned on the benchmark set (not on silicon only: generality rule).
3. Degenerate manifolds (cubic Si has triple degeneracies): real eigenvectors inside a manifold are an arbitrary real orthonormal basis; band-resolved outputs and any per-band property are gauge dependent and must be compared as manifold sums.
4. Near-zero residuals: the paired transform has partner contamination at the level of one transform's rounding (about 1e-16 relative to the combined norm); this is the same order as ordinary FFT noise, but certificates with tolerances near 1e-14 should be tested for flicker.
5. The gain is bounded by Amdahl (section 7.4): the estimate 2.1 times (1.7 to 2.4) is for the Gamma-only part of the SCF; the dense-grid, XC, mixing, setup parts are only marginally improved. A 2 times gain does not close an overall gap of 3 to 7 times to QE complex k=0 on Gamma-like cases by itself, and QE's real path is faster than its complex one by about the same factor, so the gap to QE's best configuration does not shrink by this path alone; it prevents it from widening.
6. Not applicable beyond Gamma: the path does not help the multi-k cases that dominate production use. Maintenance cost of a second solver family (real) is permanent; it must be isolated and tested.
7. G=0 handling in parallel splits (if the half sphere is distributed across workers) is a classic source of double counting; BAANDI's worker model splits by bands or pairs, not by plane waves, so the correction is applied once per product.
8. The checkpoint format: it stores full-sphere complex coefficients today (ADR and `docs/` should be checked); storing half-sphere vectors requires a version bump.

## 10. Hypotheses for BAANDI (numbered; to test one by one)
Ranking is by expected whole-run benefit per risk, with the dependence order in mind (H1 is the foundation of H2 to H5). Ledger conflicts are stated for each; none re-proposes a rejected item.

H0. Measure QE's real Gamma path on dev08 (`K_POINTS gamma`, np=1, same UPF, grid and cutoff, conv_thr 1e-12), for the Gamma-like cases (Si2 Gamma and the 8-atom cell at Gamma), as the second QE reference and the correct target for "exceed QE against its best configuration".
- Expected gain: none directly (measurement); it replaces my estimate of 1.7 to 2.3 times QE's real-over-complex advantage with a number. Basis: section 0 and 7.
- Risk: none for the code; dev08 time and the 0.01 s timer resolution (use the 8-atom cell, where the walls are larger than 0.2 s).
- Gate: command, QE version, input, UPF SHA-256 and output stored as a reference bundle per AGENTS.md; energy matches the complex k=0 run to the printed digits.
- Ledger: no conflict.

H1. Real Gamma path, stage 1: paired local-potential application and paired density accumulation on top of the existing full-sphere fused FFT plan, with half-sphere vectors and a mirror-index table; first as a standalone microbenchmark and test (pack, transform, unpack versus two single complex applications), then wired into a real Davidson that still uses simple real kernels.
- Expected gain: FFT component 2.0 times (section 7.1), about 1.2 to 1.3 times on the whole Gamma SCF by itself (FFT share 0.30 to 0.40, from the ledger's 0.30 ms per full 36^3 transform and 1.4 ms per vector application).
- Risk: medium (symmetry bookkeeping, G=0, odd band count); the FFT part is low risk because the plan is unchanged.
- Gate: pair application equals two single applications to 1e-14 relative on random real-structured vectors for cubic, skewed and elongated cells; microbenchmark at 25^3, 36^3 and 48^3 shows at least 1.8 times per band.
- Ledger: no conflict (the note 2 statement that the real pairing is "not available" referred to the complex default; this is the dedicated path that statement anticipates).

H2. Real Gamma path, stage 2: the Davidson dense products in real arithmetic on half-sphere arrays (reduced-matrix update, orthogonalization passes, correction assembly, rotation, restart contraction), the real symmetric small eigen solver, the weighted norm with the G=0 correction.
- Expected gain: GEMM family 3 to 4 times (section 7.2); about 1.3 to 1.4 times on the whole SCF when the GEMM family is 40 percent of the time. Together with H1 about 1.9 times.
- Risk: medium-high: the equivalence gate of 1e-12 Ha; possible different iteration counts at equal subspace capacity.
- Gate: section 8 items 6 and 7; SCF and Davidson iteration counts within one of the complex path on the benchmark set of ticket P10G (cubic, skewed, elongated, slab-like, small and large band counts, several projector structures, gaps small to large); energy offsets to the complex run below 1e-12 Ha.
- Ledger: no conflict. The P14B incremental reduced matrix (adopted) is carried over to the real path unchanged in structure; "no bit-identity" applies only to this new module.

H3. Real block nonlocal as two real matrix products (projection and back-application) with the per-atom coupling blocks applied between them.
- Expected gain: nonlocal share (about 6 percent in the 8-atom case) falls by 4 to 8 times, so about 1.04 to 1.05 times on the whole run; larger for many atoms or many projector channels (the 20-atom ledger fixture spends 2.8 ms per application there, which makes this item more valuable on larger systems).
- Risk: low; independent of the rest and can be tested alone.
- Gate: projections equal the complex projections of the same real-structured vectors to 1e-13; timing per block versus the current traversal on the ledger's shapes (4 atoms 257 rows, 8 atoms 2969 rows, 20 atoms 16385 rows).
- Ledger: the "per-block BLAS rewrite" for the complex path remains declined; this applies only inside the real path where association is not a contract.

H4. Pair-based work unit for threads in the real path (parallelism by pairs and by blocks of products), reusing the existing worker pool and deterministic reduction rules.
- Expected gain: restores the thread scaling that Gamma lacks today (ledger: Gamma uses one worker), up to the number of pairs (10 for 20 bands) on the FFT part; whole-run effect to be measured at T = 2 to 8.
- Risk: medium (determinism across thread counts is the contract; pair rule must be a pure function of column order).
- Gate: bit-identical energy and density hashes across T = 1, 2, 4, 8 in the real path.
- Ledger: consistent with P7P6 and P7PB (band workers); does not repeat the rejected packed-lane FFT threading.

H5. Dispatcher and configuration: automatic selection of the real path for a single k=0 unshifted calculation with a switch (`off`, `auto`) and a logged fallback reason, default `off` until H1 and H2 pass their gates, then `auto`.
- Expected gain: none directly; it is the safety mechanism that keeps the k-point path untouched.
- Risk: low.
- Gate: all existing k-point and shifted-Gamma benchmarks remain bit-identical against the stored baselines with the switch off and with the switch on (they must fall back).
- Ledger: no conflict.

H6. Half-sphere G-space bookkeeping for the density and potential grids (Hartree, local potential, mixing on N_half entries) and a real-to-complex or Hermitian-fill transform for the dense-grid steps.
- Expected gain: a few percent at most (two dense transforms per SCF iteration compared with about 160 pair-transform sets); more on small band counts or many SCF iterations.
- Risk: low-medium (changes the mixing arithmetic; mixing is already validated against QE).
- Gate: SCF iteration counts and the converged energy unchanged to 1e-12 Ha.
- Ledger: no conflict; keep behind H5.

H7. Complex-path interim experiment: none. I do not propose pairing inside the complex path, because there the wavefunctions are not real-structured and the pairing is not valid.
- Recorded so that nobody tries it.

H8 (speculative, my own derivation, not in QE). Real-structured states at the other time-reversal-invariant points (k with 2k equal to a reciprocal lattice vector, for example the zone-boundary points of an unshifted mesh): there the mirror pairs map G to G0 - G for a fixed lattice vector G0 and the wavefunction is real up to a known phase factor, so the same pairing works for those points of a mesh. In an unshifted mesh about one point in five of the time-reversal-reduced set qualifies for 4 by 4 by 4.
- Expected gain: up to 1.9 times on those points only, giving perhaps 1.2 to 1.3 times on small unshifted meshes; none on shifted meshes.
- Risk: high (new phase conventions, mixed paths inside one SCF, nonlocal symmetry has to be re-derived with the shifted structure, more tests); QE does not do it.
- Gate: only after H1, H2 and H5 are accepted; equivalence to the complex run at those k points to 1e-12 Ha.
- Ledger: no conflict; do not start before the Gamma path is done.

H9. Scaled G=0 representation (store the G=0 coefficient multiplied by 1/sqrt(2)) to remove the rank-one corrections from the dense products and norms.
- Expected gain: below 1 percent in the 8-atom case; mainly simpler products and fewer special cases.
- Risk: low-medium (every consumer of the G=0 entry must undo the scale; error-prone).
- Gate: identical results to the QE-style correction within rounding (1e-14).
- Ledger: no conflict; lowest priority.

Order of work: H0 in parallel with H1, then H5, H2, H3, H4, then H6; H8 and H9 only if the first group is accepted.
