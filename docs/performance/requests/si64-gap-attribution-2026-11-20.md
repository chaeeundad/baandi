## QE Davidson structure note and the H-column comparison (Claude QE source study, 2026-11-23; note: docs/research/qe-study/davidson-iteration-structure-gamma.md)
Inferred QE D arm at si64 np8: 13 c_bands calls + 58 iterations = 71 h_psi blocks; fixed part 13 x 264 = 3432 H columns (QE applies H to all 132 start vectors at the start of every call and keeps no H products between calls; iteration 1 corrects all 132 bands; capacity 2n = 264 so any call needing a second iteration restarts immediately); fftw 5410 includes sum_band 13 x 66 = 858 transforms, leaving 4552 in h_psi: about 4.4e3-4.6e3 H columns in total (+-150), later blocks about 24-25 active bands (about 19 % of 132). BAANDI: 6025 H columns (coarse 1753, fine 3504, verify 768), fine 3504 over 58 iterations = 60 per iteration vs QE about 78.
Consequences (orchestrator): per H column the application costs are close (BAANDI solve.apply 2.7815 s / 6025 = 0.46 ms; QE h_psi 1.91 s / about 4.5e3 = about 0.42 ms): the +0.87 s apply gap is mostly COLUMN COUNT (coarse + verification columns, about 2.1e3 more columns than QE's 4.5e3 minus BAANDI fine 3504...: BAANDI total 6025 vs QE about 4.5e3) and not slower columns. In the fine stage BAANDI applies FEWER columns than QE (3504 vs about 4.5e3) yet needs 5.77 s vs QE electrons 4.02 s: the surplus is non-apply cost per iteration (reduced solve, rotation, density/potential/energy, collectives, synchronization). QE's solver is simpler: fixed per-call overhead of 264 columns, DSYGVX on one rank, no collectives for the small solve (broadcast), convergence by Ritz-value change < ethr (no residual norm), no locking.
