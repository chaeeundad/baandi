PHYSICS CONVENTIONS (implement exactly; append to physics-conventions.md; derive and verify, do not copy QE source, which is GPL):
1. Plane-wave states |G> = exp(iG.r)/sqrt(Omega). Wavefunction coefficients c(G) over the wavefunction basis in its fixed order.
2. Ionic local potential: V_ion(G) = sum_species v_s(|G|) * S_s(G), S_s(G) = sum_{I in s} exp(-i G.tau_I), with v_s(|G|) = the P2A local transform (it already includes 1/Omega and the Coulomb tail via erf subtraction) for G != 0 and the finite alpha-Z constant for G = 0. V_ion(r) = to_real(V_ion(G)) on the FFT grid (should be real to roundoff). Provide it only for G in the density sphere (document).
3. Nonlocal KB operator: V_NL = sum_I sum_{i,j} sum_m |beta_{I,i,m}> D_ij <beta_{I,j,m}| with the same angular momentum l for i and j (D_ij couples projectors of the same l only; reject or handle D entries between different l explicitly and document). Using the Rayleigh expansion with real spherical harmonics: <G|beta_{I,i,l,m}> = (1/sqrt(Omega)) * exp(-i G.tau_I) * (-i)^l * Y_lm(G_hat) * beta_{i}(|G|), where beta_i(q) is the P2A projector transform (4*pi*int r^2 beta(r) j_l(qr) dr). For G = 0 use the Y_lm convention already defined in dft-upf (j_l(0) = 0 for l > 0). D_ij in Hartree. V_NL c (G) = sum_{I,i,j,m} <G|beta_{I,i,m}> D_ij sum_{G'} conj(<G'|beta_{I,j,m}>) c(G'). Matrix-free: form the projections p_{I,j,m} = sum_{G'} conj(P) c(G') first (a GEMM or loops), then expand; no N x N matrix.
4. Effective local potential V_eff(r) (real array on the FFT grid) enters as: (V c)(G) = gather(to_reciprocal(V(r) * to_real(scatter(c)))) with the P1A conventions (check the scaling so that for constant V(r) = v0 the result is v0*c). Exactness statement: if V_eff has Fourier components only inside the density sphere, then for G, G' in the wavefunction basis <G|V|G'> = V(G - G') exactly (no aliasing) with the FFT grid built by FftGridSpec; test this and document what happens when V_eff has components outside the density sphere (aliasing) and provide `truncate_to_density_sphere`.
5. Hamiltonian H = T + V_eff + V_NL with T = diag(0.5*|G|^2); V_eff is the caller's sum of ionic local, Hartree and XC on the grid (this ticket takes it as an input array). Implement dft_solvers::LinearOperator (apply on one vector and efficient apply_block that reuses the FFT plan and scratch; plans are reused across calls, no per-call plan creation).
