# Self-healing SCF diagnostics

Status: proposed rule catalogue, not measured recovery performance. Wraps `IterationRecord`, `density_distance`, `ScfError::Diverged` and `FixedPointCertificate` in `scf.rs`. Thresholds below are versioned diagnostic choices, not new convergence criteria or validated general defaults. [Demo](../demos/self-healing-scf.md) separates evidence from hypotheses.

Let r_i be the recorded density residual, E_i total Ha, t the active density tolerance, d_i=E_i-E_(i-1). Define epsilon=max(t*1e-6, 1e-30 Bohr^-3/2). Windows include only consecutive completed iterations under the same policy revision; reset windows on intervention. No division by zero, nonfinite input or missing history is permitted; emit insufficient evidence instead.

| Rule ID v1 | Exact predicate | Evidence | Hypothesis, never fact |
| --- | --- | --- | --- |
| `stagnation` | Last 6 finite residuals all > t, max(r)/max(min(r),epsilon) <= 1.2, last/first >= 0.95 | Six residuals, range ratio and endpoint ratio | Poor mixing or slow mode |
| `oscillation` | Last 6 finite d values: each abs(d)>energy tolerance; all 5 adjacent products < 0; last 6 residuals have last/first >= 0.9 | Energy differences, sign changes, residual ratio | Alternating response; no sign information can be inferred from residual norms alone |
| `divergence` | At i, b=min(r_1,...,r_(i-1)), b=infinity initially. Growth predicate r_i > divergence_factor*max(b,t) holds for divergence_patience consecutive steps | Current residual, prior best, factor and consecutive count | Unstable fixed-point iteration; mirrors existing guard, not an independent override |
| `nonfinite` | Any computed monitored density/energy/residual/charge scalar is NaN or infinity, or existing engine returns NonFinite | Field enum, stage, classification nan/positive_infinity/negative_infinity; JSON value=null | Arithmetic/model failure; never retry by weakening thresholds |
| `charge_sloshing_hint` | Optional explicit residual Fourier probe: q_min=min positive norm(G), L=sum over 0<norm(G)<=2*q_min of abs(delta_n_G)^2; T=sum over G!=0 of abs(delta_n_G)^2. T>0 and L/T>=0.8 for 3 consecutive probes AND stagnation predicate | L/T, q_min (Bohr^-1), grid/basis identity, probe iterations | Long-wavelength residual dominance, not proof of physical charge sloshing |

The Fourier probe is not available in `IterationRecord`; return `not_computed` until separately ticketed instrumentation exists. It must be an explicit bounded diagnostic outside the hot loop with its cost recorded. Never substitute cell aspect ratio or total residual for the measured L/T. Charge errors are conservation evidence, not proof of sloshing. Existing negative-density/divergence safeguards remain authoritative.

Diagnostic wire record: `diagnostic_id:string`, `rule_id` (table enum), `rule_version:"1.0"`, `iteration_first:u64`, `iteration_last:u64`, `policy_revision:u64`, `status:triggered/clear/insufficient_evidence/not_computed`, `evidence:object`, `hypothesis:null|poor_mixing/alternating_response/unstable_iteration/arithmetic_failure/long_wavelength_mode`, `suggested_action:none/reduce_beta/reset_history/new_calculation`, `severity:info/warning/error`. Evidence is a tagged typed object: stagnation `{residuals:f64[6],range_ratio:f64,endpoint_ratio:f64}`; oscillation `{delta_energy_ha:f64[6],sign_changes:u64,residual_ratio:f64}`; divergence `{residual:f64,prior_best:f64|null,factor:f64,count:u64}`; nonfinite `{field:string,stage:string,classification:enum}`; sloshing `{fractions:f64[3],q_min_inverse_bohr:f64,grid_digest:string,probe_iterations:u64[3]}`. Missing evidence uses null and `status` explains why. No free-form diagnostic text is executable.

Deterministic recovery candidate: on first stagnation/oscillation warning, beta := max(0.05,beta/2) and reset history; allow at most three interventions with at least six completed iterations between them. If beta cannot decrease, stop proposing. This is a demo policy only; does not change engine defaults. Divergence/nonfinite terminates the attempt; a new compatible warm-start attempt requires an explicit decision, and nonfinite data cannot be reused. P10D's preconditioned mixers require their own capability and evidence gates before use. P7PC's band-count remedy requires a new calculation under v1.

## Additional failure catalogue for the three-mode runtime

The following rules extend v1.0 while it is still a design, not an implemented/public schema. `eigensolver_nonconvergence`, `invalid_values` and `resource_exhaustion` are error diagnoses. A diagnosis can end the attempt without any completed `IterationRecord`; its event records `attempted_iteration=iteration_done+1` and the solve/certificate stage. No partial failed solve is turned into a successful SCF iteration.

| Rule | Exact numeric/type definition | Evidence fields | Inference and response |
| --- | --- | --- | --- |
| `eigensolver_nonconvergence` | Trigger only on typed `SolverError::NotConverged` or merged solver's equivalent typed terminal error; iterations reached its bound or solver explicitly returned nonconvergence. Never infer failure merely because current residual > tolerance during a still-running solve | `solver:davidson/hybrid`, `inner_iterations:u64`, `iteration_limit:u64`, `max_residual_ha:f64|null`, `requested_tolerance_ha:f64`, `strict_max_residual_ha:f64|null`, `buffer_max_residual_ha:f64|null`, `k_index:u64|null`, `error_code`, `stage` | `insufficient_subspace/degenerate_boundary/poor_guess/unknown` are hypotheses only. Compatible preauthorized fallback is owned by solver; terminal failure requires explicit new attempt, not weaker tolerance |
| `invalid_values` | Any nonfinite scalar/array element checked by existing numerics; mixed density < -1e-14 electron number/Bohr^3 (existing `xc::NEGATIVE_ROUNDOFF` guard); invalid parameter beta not in (0,1], history<1, nonpositive tolerance, malformed shape/unit rejected by control/import validation | `field`, `stage`, `classification:nan/positive_infinity/negative_infinity/negative_density/out_of_range/shape/unit`, `value:f64|null`, `lower_bound:f64|null`, `upper_bound:f64|null`, `element_index:u64|null` | `arithmetic_failure/invalid_input/unknown`; never identify an upstream cause from invalidity alone. Reject invalid control without changing state; invalid numerics fail attempt |
| `resource_exhaustion` | Budget B is positive integer; current measured usage U>=B stops before further work; preflight predicted next allocation/work would exceed B rejects that operation. Exact prediction is required to call it measured; otherwise label estimate. Event/critical credit unavailability is a separate explicit exhaustion condition | `resource:iterations/operator_applications/memory_bytes/wall_nanoseconds/artifact_bytes/critical_event_slots`, `used:u64`, `limit:u64`, `next_estimate:u64|null`, `measurement:actual/estimate`, `boundary_iteration:u64` | `budget_too_small/workload_cost/consumer_or_storage_stall/unknown`; no inference of physical divergence. Stop/deny under quota, optionally request authorized extension |

The existing engine's `ScfError::Numerical(String)` can obscure a typed solver error through conversion. Do not parse human error strings to invent band indices/residuals. Report null/not_computed until a separately reviewed typed adapter preserves those fields; P10A/P7PC may supply richer data, but unmerged code is not a current capability. `nonfinite` remains the narrowly defined arithmetic subrule of `invalid_values`; reference one evidence record rather than count the same failure twice.

The earlier flat `evidence`/`hypothesis` fields are replaced by separate required objects in the expanded DiagnosticRecord (the hypothesis codes remain inference codes): `evidence:{source:iteration_record/solver_error/control_validation/resource_meter,observed_state_version:u64,measurement:actual/estimate,values:RuleEvidence,unavailable_reason:string|null}` and `inference:{code:enum,confidence:not_calibrated,alternatives:string[],recommended_action:enum}|null`. RuleEvidence is the finite typed object defined by its catalogue row. Confidence is deliberately not a probability without calibration. No asserted causal claim is permitted in evidence. Full rule windows/per-band vectors live only in bounded evidence artifacts; events flatten scalar summaries and carry `evidence_id`, never arrays.

For `diagnostic_active(...,minimum_consecutive=m)` preconditions, m>=1 counts consecutive boundary evaluations with triggered status under the same policy revision. Clearing, missing evidence or revision changes reset the streak. Evaluate error rules before advisory rules; if data is invalid, suppress ratios and oscillation conclusions for that window. Rule outputs do not change candidate convergence or the certificate.

Resource meters are driver-side, not new hot-loop logging. Iteration/operator counts reuse existing solve/certificate totals; memory and wall meters are boundary samples and can lag one full step. Call a requested cap a target/estimate if it cannot be enforced before an allocation; OS process limits may enforce a hard ceiling but can terminate without an exact partial-step checkpoint. Critical queue exhaustion uses the failure semantics in [events](../architecture/scientific-state-api.md), independent of an agent's connection state.

Event `diagnostic.scalars` uses these fixed per-rule subsets (all unavailable numeric values null with reason): stagnation `range_ratio/endpoint_ratio/sample_count`; oscillation `sign_changes/residual_ratio/sample_count`; divergence `residual/prior_best/factor/count`; nonfinite/invalid_values `value/lower_bound/upper_bound/element_index`; charge_sloshing_hint `low_q_fraction/q_min_inverse_bohr/probe_count`; eigensolver_nonconvergence `inner_iterations/iteration_limit/max_residual_ha/requested_tolerance_ha`; resource_exhaustion `used/limit/next_estimate`. Count/index fields are u64, other numbers finite f64. Type-specific classification/source/measurement enums are in details alongside evidence_id/inference_code; full evidence arrays are never embedded. This projection does not compute a diagnostic from an already coalesced stream: driver diagnostics use the authoritative bounded history before delivery loss.
