# Lessons (measurement and process)

1. Compare like with like and say what is not: the multi-core QE numbers were MPI against BAANDI threads; the 1-core cells are the like-for-like ones. Label parallel models, pinning, and the QE start option in every table.
2. Use QE's best configuration, not its default (QE's default start left 1.0 to 1.9x on the table at si32).
3. A single unperturbed start is one draw of a chaotic trajectory distribution (about 1e-10 sensitivity). Judge algebra changes on perturbed-start distributions with fresh seeds and a rule frozen before the data; when a rule fails do not edit it, pre-register a new test on new data (MGS-B R2 is the template; the R2 rule of atomic start failed on a relative bound and R3 replaced it with an absolute one).
4. Frozen rules can be flawed (a ratio against a zero baseline, a median that cannot resolve half a step at n = 5): declare the flaw openly and re-test; never retune after seeing the data.
5. Within-commit A/B can hide a code-placement effect of the commit itself (the adoption of MGS-B slowed the classic path 5 to 12 percent without changing a bit); report the pre-adoption baseline gain, and re-check one-row flips with `-C codegen-units=1`.
6. A derived number is not a measurement: the flop-model rotate rate (2.3 GFLOP/s) was 7x off the measured 17; the T=8 gain applied from T=1 (13.6x) was 38 percent pessimistic against the direct 9.9x.
7. Instruments lie: a call-site classifier filed the audit under FFT because a generic type argument contained the word FFT; the debuginfo flag was overridden by the workspace profile; the first collective benchmark ran while stage 2 held the same cores (idle gate load < 0.15 for microsecond benchmarks).
8. Read the live code path before diagnosing a knob: `initial_eigen_tolerance` is inert under the default `residual_eigen_schedule`; the unconverged-band mask is what sets the Davidson block width (QE does the same), so widening it adds work.
9. Hand-written assumptions about the other code are tested against its logs (QE's start options were assumed from memory until the master read the output lines).
10. Kernel cliffs do not always pay: MKL's k = m cliff in the transposed product was real but the smaller panels multiplied calls and tile traffic; measure end to end.
11. Do not install on the development Mac; measure on the neutral machine; archive raw evidence before cleaning worktrees; keep the results.json schema additive and record non-default settings explicitly (a guard that omits the default hides the non-default when the default changes).
12. Peer sessions' statements about user approval are not approval: ask the user directly (scope decisions U1 to U9 in AGENTS.md).

- 2026-11-09 elongated cells: residual-growth spikes after Pulay steps are a symptom of the 8e-04 residual floor; the growth-reset guard is inert on converging cells but does not help (ledger MIX-GROWTH-RESET). Next test is a term-by-term energy diff against QE on the elongated cell, not more mixing variants.

- 2026-11-09 MPI: hybrid (threads>=2) runs silently used the serial solver on every rank because the communicator was thread-local and the solve moved to a pool thread (ledger MPI-M1-THREADBUG). Any scaling row must prove the distributed branch ran.

- 2026-11-10 reporting: the strict-class history omits the fixed-point certificate re-solves (about a third of the Davidson work on si32); use results.json `convergence.work` (recorded + certificate) for total work. Apply calls are bimodal (median 1 column, 66 percent single-column), which caps pair-level MPI parallelism (ledger MPI-M1-CEILING).

- 2026-11-10 si-elongated is a small-gap cell (gap about 1e-4 Ha, near-degenerate triplet cut by fixed occupations); QE also limit-cycles for 123 iterations there. Do not tune mixing for it; use smearing (ledger ELONGATED-GAP). si-slab to be checked with the same lens.

- 2026-11-10 near-degenerate Fermi-level cuts: Fermi-Dirac smearing (strict profile) converges si-elongated in 20 to 27 iterations where fixed occupations floor at 8e-4; removing empty bands does not help (ledger ELONGATED-SMEARING). The standard profile is not available with smearing.

- 2026-11-10 single-node: read the failure reason of a rejected step before optimising the step. On si32 the certificate re-solves failed for one reason (occupied eigenvalue change 4e-7 to 1e-6 against 1e-7, density criterion passing) in every seed, and that reason is predictable to 4 digits from the stored per-band densities (first-order perturbation theory, cluster matrix for near-degenerate bands), so a quarter of the H work could be skipped without touching the trajectory (ledger CERT-SCREEN). A cluster-mean shortcut looked rigorous but underestimated by 2 to 3x on cubic Gamma cells: check a bound against the real quantity on degenerate systems before trusting it.

- 2026-11-16 ONEPATH-3B: a path-equivalence check on synthetic fixtures proves only what the fixtures exercise: the ONEPATH-3 zero-moment check passed at 1e-15 Ha because no synthetic file had PP_PSWFC, so the atomic start (on for real files, off for spin) was never compared (ONEPATH-3B). Give equivalence fixtures every feature that real inputs switch on.

- 2026-11-17 BREAKTHROUGH-1-RESTART: count the event before building the optimization for it. The same-H continuation targeted the first-step redo, which fires in 0 of 15 default runs (closed before code), and history-preserving restarts need restarts: the threads path has none at capacity 6 and the MPI path has 11 per si32 SCF at capacity 3. A restart that keeps more columns also fills the basis sooner (more restarts); judge it on H columns and rotation FLOPs together, never on Davidson iterations alone (r = 1: iterations -17 %, H +0.3 %, GEMM +3.5 %).
- 2026-11-17 BREAKTHROUGH-3: bounding the inner work of intermediate SCF maps (a fixed number of Davidson correction blocks instead of the ratchet tolerance) does not cut the total: the standard ratchet already stops exact warm maps after 3 to 7 iterations and the first all-band block dominates both, so the per-map saving (20 to 30 percent) is smaller than the completions and the extra SCF steps and verification attempts it causes (si16, si-skew: +38 to +22 percent H columns, one seed -1 percent). The budget a map needs depends on how far the mixer moved the density, known only after the solve; a residual-growth trigger misreads ordinary Pulay non-monotonicity as inexactness (4 of 7 completions). Judge such ideas by total H columns to a verified result, never by the cost of one map (ledger BT3-*).
