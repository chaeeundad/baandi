# Documentation map

| Need | Where |
| --- | --- |
| Rules for agents, read order | `../AGENTS.md` |
| Who may edit what; crate dependency graph | `../ownership.toml` |
| Per-crate purpose, invariants, verify command | `../crates/<name>/AGENTS.md` (generated by `scripts/gen_crate_guides.sh`) |
| Ticket format and active tickets | `../tickets/TEMPLATE.md`, `../tickets/<TASK_ID>.md` |
| Architecture and API sketches | `architecture.md` |
| Measured environment (toolchain, Accelerate, FFI notes) | `environment.md` |
| Dependencies, licenses, pinned versions | `dependencies.md` |
| Decisions (immutable, append new ones) | `decisions/` (0001 backend isolation, 0002 FFT backend, 0003 general-purpose libraries, 0004 backend libraries); `backend-spike-results.md` holds the measurements behind 0004 |
| Current state and history | `progress.md`, `../artifacts/*.json` |
| Codex run registry (PID, role, session, status) | `../artifacts/sessions.json` |
| Report schema for Codex results | `schemas/report.schema.json` |
| QE reference environment and run protocol | `reference-environment.md` |
| Physics conventions, units, normalization (to be written in P1) | `physics-conventions.md` |
| Validation evidence and reference provenance (to be written in P6) | `validation.md` |

Conventions: docs are English; one fact lives in one place and others link to it; an ADR is never edited after acceptance, supersede it with a new one; numbers recorded as references must carry command, version, input and SHA-256.
