# ADR 0026: Agent-native runtime boundaries and contracts

- Date: 2026-11-03
- Status: proposed; design commitments only, implementation and acceptance pending.
- Number check: originally drafted as 0020; read-only inspection found competing uncommitted P10A/P10D ADRs numbered 0020. P11I subsequently created `0021-coupling-api-split.md`; final recheck therefore selected 0022, free in main and the inspected task worktrees on 2026-11-03. Recheck concurrent ADR reservations at integration; no accepted ADR was edited.
- Context: [directive review](../research/agent-native-directive-review.md), [P11 common rules](../../tickets/P11-COMMON.md), live `ScfProblem::run_impl` and `step_kpoints`. A runtime must expose existing scientific behavior without introducing agents into numerics or creating overlapping state/control systems.

## Commit now

1. Five downward layers: numerical core, typed scientific state, safe-point control, external integration, agent tools. Pure state/session modules live in dft-engine; persistence/events/scheduling are CLI adapters. No new crate before the stepwise API and a demonstrated independent consumer justify a split.
2. Additive `new/initialize/step/result` session semantics: one step is one complete SCF iteration including applicable mixing and any nested certificate. Preserve legacy strict versus retained-result termination semantics. Conventional run paths become thin drivers only after bit-identity gates pass.
3. Existing fixed-point certification is the only convergence authority. Agents cannot set convergence, modify physical models live or loosen tolerances. Typed transactional policy changes apply only at complete boundaries and have immutable audit records.
4. Versioned bounded read-only snapshots, JSON-lines events and explicit unit contracts; no serialization, strings executed as commands, networking, LLM/MCP/Python dependencies or new logging in numerical hot loops.
5. One checkpoint envelope for P11C/A4 and ESLE phase B: ElectronicState is its scientific payload. Exact continuation, warm start and result export are distinct validated capabilities; no silent downgrade. The ESLE save/load sketch belongs to CLI persistence.
6. Runtime adapters are ADR 0017's coupling runtime layer. No second coupling controller. External fields, derivatives and coupled energy accounting remain separately gated physical capabilities. P9A consumes the single P11F MCP server. P10D owns mixer algorithms/parameters; runtime owns validation, safe application and audit, not a second mixer implementation.
7. Deterministic replay is conditional on the complete execution identity and boundary-indexed policy log. Wall times are not numerical identity. Evidence and diagnostic hypotheses remain separate.
8. Self-healing claims require a frozen failing baseline, no-intervention/rule/recorded-agent arms and a fully converged same-model reference. The initial guaranteed budget-failure demo is explicitly narrower than numerical-instability recovery.

## Three-mode commitments (2026-11-03 addendum)

9. `Classic`, `Observed`, `AgentControlled` are typed execution policies over ONE extracted SCF iteration, not three engines. Classic has no events, telemetry serialization or agent; Observed adds bounded read-only events/on-demand snapshots and never waits for a subscriber; AgentControlled adds safe-point requests, default supervised approval, bounded autonomy and recorded fallback. Existing numerical history remains in every mode.
10. Choose mode at creation. Before initialization the creation config may change. After start, Classic cannot upgrade because there is no prior stream; Observed and AgentControlled may switch only at Ready/Paused boundaries with operator approval and durable audit. Neither may downgrade to Classic; terminal mode changes reject. A switch must not alter numerical settings, density, orbitals or mixer history. Downgrading AgentControlled rejects pending proposals, revokes autonomy and retains its prior audit; it does not undo already applied numerical changes.
11. Keep fast/control/agent paths separate. Fast FFT/BLAS/Hamiltonian/eigensolver code has no network/LLM/serialization; the control path evaluates bounded diagnostics and typed requests at boundaries; the agent asynchronously proposes, never decides convergence. If iterations finish before an LLM reply, continue under the current policy and reject/revalidate the late request using state version, predicates and expiry. Never insert an implicit LLM wait into SCF.
12. Events have calculation id, monotonic seq, SCF iteration, state version, type, timestamp, typed scalars and schema version, with no arrays. Bounded nonblocking queues may drop/coalesce routine telemetry with an explicit count event. Certificates, state/mode transitions, admitted control dispositions, errors and loss summaries are never silently dropped. Journal/replay decouples slow subscribers; exhausted critical storage stops at a safe point with a resource failure rather than making an impossible infinite lossless queue promise.
13. Each ControlRequest binds observed version, action/parameters, preconditions and expiry. Distinguish accepted, rejected and applied events; apply an approved change atomically against the revalidated boundary. Stale observations are not authority. Autonomy is opt-in through a hashed allow-list with ranges/counts/cooldown; absent agent defaults to continue_current. No tolerance is weakened. Live mixer/solver selection reuses only compatible merged P10D/P10A/P7PC implementations.
14. Targets, not measurements: Classic overhead <0.5%, Observed <1%, AgentControlled without intervention <1%, relative to a matched pre-refactor run. P11J owns measured evidence including short workloads, saturation and checkpoint/control cost. P11H owns CLI experience over these contracts. P11I owns high/low-level coupling and active-learning API specifications; P11R owns only their runtime boundary and E1/E2 runtime provenance/workflow semantics.

See [execution modes](../architecture/execution-modes.md) for the normative switch table and latency behavior, [events](../architecture/scientific-state-api.md) for queue/overflow rules, and [control](../architecture/runtime-control.md) for requests, examples and approvals.

## Deferred

Implementation of all proposed APIs and schemas, crate splits, concrete Python/ASE/MCP dependencies, checkpoint migrations, exact replay across builds/backends/thread counts, in-flight Davidson persistence, new preconditioners, external numerical solver transport/ABI, MLIP calibration and workflows, provenance/DAG execution, forces/stress, charged or density-dependent coupling. No stub capability may advertise these as available. P11A waits for P10A/P10D/P10C/P7PC merges and rechecks live code.

## Alternatives rejected and consequences

Reject a second ESLE checkpoint format or P9A MCP server (competing identity and validation); per-eigensolve public “steps” (unsafe mixing/certificate boundaries); automatic tolerance relaxation (changes the scientific question); beta=100 as an allowed self-healing input (violates the new safety contract); universal bitwise restart claims (unproven backend/state compatibility). Preserve current APIs and defaults. Implementers must measure both overhead and numerical equivalence, and cannot infer completed work from this design.
