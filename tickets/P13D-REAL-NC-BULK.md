TASK_ID: P13D-REAL-NC-BULK
GOAL: Make the real PseudoDojo NC-SR v0.4 PBE standard files run in bulk systems that are insulators with fixed occupations, using the NLCC support delivered by P13C. P13C result: infrastructure done (parser, NLCC Fourier transform and XC core density, ledger, inspection tool, manifest, oracles), but the isolated-atom smoke runs failed: O and Ni aborted in iteration 1 because of a negative combined (valence plus core) density, Al diverged (53 iterations at 20 Ha, limit at 30 Ha), Si hit the 60 iteration limit, only Mg (no NLCC) converged (14 iterations). Isolated atoms were the wrong test: an open-shell atom with fixed integer occupations is not a valid insulating system (O has a partly filled p shell, Al has 3 electrons, Si and Ni have degenerate partly filled shells), the engine correctly assumes fixed full occupations. This ticket replaces the smoke test by physically valid bulk insulators and fixes what the real files then expose.
