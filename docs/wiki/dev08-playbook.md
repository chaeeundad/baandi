# dev08 playbook

Measurement runs through the master session (dft5090); the orchestrator never runs remote builds itself. Machine: 2 x Xeon Gold 6230, 20 cores per socket, 2 threads per core (CPUs 0 to 19 and 40 to 59 on node 0), Open MPI 5.0.8 (shm and tcp only), oneMKL 2026.1, builds under /scr/mino/rustdft/ (home partition is small, nothing is deleted).
- Pinning: `taskset -c 0-(N-1)` for threads (distinct physical cores of socket 0); QE `mpirun -np N` default binding is the same cores. Idle gate: load < 0.30 for second-scale runs, < 0.15 for microsecond collectives. Build flags: `RUSTFLAGS="-C target-cpu=native"`, MKL builds `--features mkl` with MKLROOT, MPI builds `--features mpi` with `MPICC=~/fq/deps/bin/mpicc`.
- Protocol: paired alternating rounds in one binary through an environment switch, n = 5/5/3 unperturbed, perturbed starts (+-1e-7 Bohr, seeds in blocks 501.., 601.., 701.., 801.. never reused across rules), strict and standard classes, density SHA recorded (stable run to run, equal T=1 versus T=8), energy and |dE| against the tight reference (strict 1e-10 Ha class, standard 5e-9).
- Switches (environment): `BAANDI_MKL_DGEMM=off` (MKL dgemm products), `BAANDI_MKL_EVD=off` (dsyevd), `BAANDI_MGS=classic|blocked` (default blocked on MKL), `BAANDI_ROTATE_KERNEL=blocked` (rejected research kernel), `BAANDI_DGEMM_TIMERS=1` (with build feature `dgemm-timers`: per-site calls, seconds, flops), `BAANDI_CERT_SCREEN=on|trace` (skip certain-to-fail certificate re-solves, strict class; trace prints estimate and actual to stderr), `BAANDI_NL_ENERGY=fast` (projection-only nonlocal energy in the audit), `BAANDI_POTENTIAL_REUSE=off` (with the screen on: disable reuse of the screen's Hartree/XC fields by the certificate solve; reuse is on with the screen by default and bit-identical; trace lines carry `screen_s=`), `BAANDI_ENERGY_IDENTITY=on` (B2: non-final iterations take E_nl from the band-sum identity, so history `energy` is the band-structure form; final energy is the explicit audit; `convergence.work.energy_identity` reports the final-state difference; integer-occupation spin-unpolarized driver only, Fermi-Dirac and spin keep the explicit audit). Config keys: `scf.gamma_real` (auto), `scf.start_wavefunctions` (atomic), `scf.start_density` (uniform), `pseudo.local_mesh` (baandi, qe_like, qe_like_g0), `[compat] mode = "reference"` (PBE only).
- Switches (environment): `BAANDI_MKL_DGEMM=off` (MKL dgemm products), `BAANDI_MKL_EVD=off` (dsyevd), `BAANDI_MGS=classic|blocked` (default blocked on MKL), `BAANDI_ROTATE_KERNEL=blocked` (rejected research kernel), `BAANDI_DGEMM_TIMERS=1` (with build feature `dgemm-timers`: per-site calls, seconds, flops), `BAANDI_CERT_SCREEN=on|trace` (skip certain-to-fail certificate re-solves, strict class; trace prints estimate and actual to stderr), `BAANDI_NL_ENERGY=fast` (projection-only nonlocal energy in the audit), `BAANDI_DAVIDSON_STAGES=on` (real Davidson stage timers into `convergence.work.davidson_stages`), `BAANDI_B1=standard|strict|on` and `BAANDI_B1_SKETCH=count` (selected-root products, counters in `convergence.work.b1`), `BAANDI_B5=on` (bordered reduced eigen-update, counters in `convergence.work.b5`). Config keys: `scf.gamma_real` (auto), `scf.start_wavefunctions` (atomic), `scf.start_density` (uniform), `pseudo.local_mesh` (baandi, qe_like, qe_like_g0), `[compat] mode = "reference"` (PBE only).
