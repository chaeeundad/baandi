TASK_ID: P48E-WIDTH-FLOOR
GOAL: Remove single-column Davidson steps from non-final steps without touching any stopping rule, by giving narrow steps a minimum correction width w_min. Extra columns are corrections of other roots, so the Rayleigh-Ritz subspace only grows: by the Courant-Fischer minimax property the Ritz values of the lowest roots cannot rise, and the solve stops by exactly the same predicate as today. The change trades extra H applications per narrow step for fewer narrow steps and turns BLAS-2 steps into BLAS-3 steps. Rounding class (different trajectory to rounding, same converged state within the accuracy classes). Accuracy contract: docs/performance/requests/p48-work-order.md section 2.
