PHYSICS_CONVENTIONS (implement exactly and append to docs/physics-conventions.md):
1. Miller indices (m1, m2, m3) in Z^3 label G = m1 b1 + m2 b2 + m3 b3 (B from dft-geometry, Bohr^-1).
2. Wavefunction basis: all G with 0.5*|G|^2 <= Ecut_wfc (Hartree), full sphere including G = 0 and both G and -G (complex Gamma-only, NOT the QE real-Gamma half sphere). Boundary: include when 0.5*|G|^2 <= Ecut*(1 + 1e-12); state this and test it with a cubic cell where a shell lies exactly on the cutoff.
3. Density sphere: all G with 0.5*|G|^2 <= 4*Ecut_wfc (i.e. |G| <= 2*Gmax_wfc), same boundary rule. Product of two wavefunction components stays inside this sphere.
4. FFT grid rule (independent implementation, documented): let M_i = max |m_i| over the density sphere. Required n_i >= 2*M_i + 1 so every density-sphere index maps to a distinct grid index. Then round n_i up to the next integer whose prime factors are only 2, 3 and 5. Allow an explicit user override of (n1, n2, n3); an override smaller than the required size is an error (typed), a larger one is accepted. Do not claim this equals QE's choice; P6 compares.
5. Index mapping: Miller index m on an axis of length n maps to grid index m if m >= 0, n + m if m < 0, consistent with the frequency rule already in physics-conventions.md. Reject any index with |m| > allowed range (typed error).
6. Ordering: deterministic order of G-vectors: ascending |G|^2 (compare with a tolerance-free exact tie-break: then by (m1, m2, m3) lexicographically). Document it.
7. Coefficient vectors c(G) are ordered like the G list; scatter puts c(G) into an Array3<Complex64> at the mapped indices (zeros elsewhere); gather reads them back.
8. Normalization check: with psi(r) = Omega^(-1/2) sum_G c(G) exp(iG.r) and sum |c|^2 = 1, (Omega/N) * sum_r |psi(r)|^2 = 1 using the P1A to_real transform.
