TASK_ID: P43A-BAND-FRACTION-RULE
GOAL: Test, on NEW systems and perturbation distributions, the exploratory hypothesis that extra bands of about 0.35 to 0.4 times the number of occupied bands remove the SCF instability of Gamma-only cells with many occupied bands, and add the rule as an opt-in if a preregistered rule passes. Read docs/performance/band-cut-stability.md (including the addendum), band-boundary-policy.md and P42A-evidence/summary.csv (archived: ../rust-dft-wt/archive/P42A-evidence.tar.gz; extract into a scratch directory outside the repository, do not commit it), trajectory-divergence.md (P41A), band-count-scan.md, AGENT-BRIEF.md and the ledger (A19, P38A, P42A, P41A). Facts: with the default of four extra bands the standard-profile SCF of si8-gamma (16 occupied bands) ranges 20 to 32 and of si16-gamma (32 occupied) 15 to 27, and the work varies 1.5 times; with extra >= 6 (si8) or >= 10 (si16) every perturbed start follows one trajectory (SCF 9 to 10) and the H work falls by 40 to 50 percent; cells with few occupied bands or k meshes are already stable at the default. The reference code is stable with nbnd equal to the occupied count.
RULE UNDER TEST (declare and freeze it BEFORE measuring; record it in the document): extra = max(4, ceil(f * occupied)) for Gamma-only calculations, with f = 0.375 (so si8: 6, si16: 12, si32: 24); for k-point calculations and spin/FD paths the default of four is kept (state this scope limit). The occupied count is known at setup, so the rule is deterministic, independent of the thread count, identical at all k points and the same in every code path.
NEW EVALUATION SYSTEMS (not used in the P42A scan; Si.pz-vbc.UPF at ../rust-dft-wt/pseudo; PseudoDojo files in ../rust-dft-wt/pseudo/pseudodojo, never copy or commit UPF files): (a) si32-gamma (benchmarks/cases; 64 occupied bands: extra rule 24; this run is long on the Mac: one strict reference run and 5 standard perturbations are enough, real path only), (b) a skewed 16-atom Si cell (Gamma only), (c) an elongated 12-atom Si cell (a 1x1x1.5 or 2x1x1 conventional-cell variant that converges; check it converges at all with the strict reference, otherwise drop it and say so), (d) a PseudoDojo MgO 2x2x1 supercell or the largest MgO/Si material that is Gamma-only and runs in reasonable time, (e) an 8-atom synthetic fixture with a different projector structure if one exists, plus the previously scanned si8 and si16 as a consistency check (not as evidence). For each system: SCF min/median/max and H work median for the default (extra 4) and the rule's count (and, where cheap, extra 6, 10 and one count above the rule), standard profile with 10 perturbations (1e-10 relative start-density noise, the P29A harness env `P29A_EXTRA_BANDS`, `P29A_GAMMA_REAL=on` for the real path; complex path as well where affordable), and strict profile (2 references), delivered accuracy against the strict tight reference, failures.
