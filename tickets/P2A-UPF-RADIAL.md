PHYSICS AND UNIT CONVENTIONS (derive, implement, test, and append to physics-conventions.md):
1. Units in UPF v2 (confirm from the specification, then encode once): potentials PP_LOCAL and D_ij in Rydberg, PP_BETA stored as r*beta(r) in the unit stated by the specification, radial grid PP_R in Bohr with PP_RAB the integration weights. Convert exactly once at parse time into Hartree atomic units in our validated type (keep the original arrays untouched in a raw field if useful). Test the conversion with a fixture whose Rydberg values are known.
2. Validated type fields at least: element, z_valence (f64, must be positive and finite), functional string, mesh r and rab (strictly increasing r, positive rab, equal lengths, finite, r[0] >= 0), local potential in Hartree, for each projector: angular momentum l and the radial function in the convention you document, the number of valid points (cutoff index), D_ij matrix in Hartree (must be symmetric/Hermitian within a stated tolerance; real in UPF), number of projectors consistent between PP_BETA entries and PP_DIJ dimensions.
3. Simpson integration on the mesh using rab, with an odd/even point-count rule that you document and test against analytic integrals (for example exponential and Gaussian integrands on a logarithmic mesh like UPF meshes: r_i = r0*(exp(i*dx) - 1), rab_i = dx*(r_i + r0) ). Report measured error vs mesh density.
4. Spherical Bessel functions j_l(x) for l = 0..3: stable for all x >= 0 including very small x (series) and large x (closed form or recurrence); tests: closed forms, recurrence j_{l-1} + j_{l+1} = (2l+1)/x * j_l, small-x limit x^l/(2l+1)!!, Wronskian-type identity with y_l if you implement it, tolerance 1e-13 relative away from zeros.
5. Real spherical harmonics Y_lm, l <= 3, with the standard real combination and normalization integral_{S^2} Y_lm Y_l'm' = delta delta. Tests: orthonormality by quadrature on a Gauss-Legendre x trapezoid grid (state its size) to 1e-12, and the addition theorem sum_m Y_lm(a) Y_lm(b) = (2l+1)/(4*pi) P_l(a.b) for random unit vectors to 1e-13. Define the ordering of m and write it down.
6. Local potential transform. Let V(r) be the Hartree-unit local potential with long-range tail -Z/r. For a cell of volume Omega define the Fourier component V_loc(G) = (1/Omega) * integral V(r) exp(-i G.r) d^3r for G != 0. Handle the tail analytically: write V(r) = [V(r) + Z*erf(r)/r] - Z*erf(r)/r, integrate the short-range bracket numerically with sin(Gr)/(G r) kernels (4*pi*int r^2 [..] sin(Gr)/(Gr) dr / Omega), and add the analytic transform of -Z*erf(r)/r which is -4*pi*Z*exp(-G^2/4)/(Omega*G^2). Provide a separate G = 0 quantity: the finite "alpha Z" term (1/Omega)*integral 4*pi*r^2 [V(r) + Z/r] dr (state precisely which finite constant is returned and how it combines with the Hartree and Ewald G=0 conventions: the divergent 1/G^2 parts are dropped consistently; document that the erf subtraction changes the finite remainder by a known constant and implement the correct bookkeeping; verify it numerically). Integration upper limit: parameter r_max with default min(mesh end, 10 Bohr); test convergence in r_max on a synthetic potential and report the sensitivity. Verification with closed forms: V(r) = -Z*erf(r/rc)/r has the exact transform -4*pi*Z*exp(-G^2*rc^2/4)/(Omega*G^2); also V(r) = -Z*erf(r/rc)/r + A*exp(-r^2/s^2). Agreement < 1e-8 relative for G between 0.1 and 12 Bohr^-1 on a UPF-like logarithmic mesh; report measured errors. For the G = 0 constant use a case with a closed form too.
7. Projector transform: beta_l(q) = 4*pi * integral r^2 beta(r) j_l(q r) dr (beta(r) is the radial function with the 1/r from the UPF storage removed correctly: derive and document), without the 1/sqrt(Omega) and without Y_lm, (-i)^l, structure factor (those are assembled in P2B). Verification: Gaussian projector beta(r) = r^l exp(-r^2/(2 s^2)) has a closed-form transform for l = 0, 1, 2; compare to < 1e-9 relative; also test the Parseval-type identity: (2/pi) integral q^2 |beta_l(q)|^2 dq equals 4*pi... derive the exact statement for your normalization and test with the Gaussian.
8. Interpolation or tabulation is optional; if you add a table for repeated |G| evaluation state the interpolation error and test it. Direct evaluation per |G| is acceptable for now.
