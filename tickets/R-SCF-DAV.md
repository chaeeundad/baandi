GOAL: |
  Part of the new SCF path (GitHub issue #25; read docs/design/reference-scf.md). User decisions 2026-11-23: the legacy SCF machinery is being replaced; old code need not be preserved; bold rewrites are allowed where they promise speed. This ticket writes a NEW inner eigensolver for the reference SCF driver, organized like the QE 7.6 real-Gamma Davidson so that the inner solve can be compared iteration by iteration with QE (patch 2 aligns "inner tolerances and stopping semantics") and so that its per-iteration non-H cost can be made small.
  Measured motivation (dev08, si64 np8): per Davidson iteration BAANDI costs 99 ms versus QE 69 ms with the same iteration total (58); QE's whole non-H, non-eigensolve subspace algebra is 0.78 s while BAANDI's Gram + rotate + kept_update is 2.53 s; QE's dense small solve (0.88 s, 69 calls) is comparable to BAANDI's reduced_eigen (0.99 s, 183 calls). The ONLY description of QE's algorithm you may use is docs/research/qe-study/davidson-iteration-structure-gamma.md (our own words) plus the literature (Davidson 1975; Liu; Kresse-Furthmueller 1996 for the preconditioner). Never look for or use QE source. Ledger rows on rejected ideas (REL-SLICES, Advance/bounded subspace, restart-keep, PR-CG, GEMM call-shape changes UPPER_BORDER/ROTATE_COLUMNS, packed reductions) stay closed; this solver is a different organization (QE-like block structure), not a repeat.
